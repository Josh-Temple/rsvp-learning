# 学習教材原稿生成用プロンプト

以下の指示は、調査結果や学習したいテーマから、人間が先にレビューできる教材原稿を作るためのテンプレートです。

内容品質のレビュー基準は `docs/CONTENT_QUALITY_STANDARD.md` を参照してください。

---

与えられたテーマまたは調査結果を、学習用の短い日本語教材へ再構成してください。

この段階では RSVP JSON を作らず、まず人間が通常の文章として内容を確認できる原稿を作ってください。

## 内容

- 事実、解釈、推測を区別してください。
- 重要な条件、例外、限界を落とさないでください。
- 元資料の長い文章を転載せず、独自の説明文へ再構成してください。
- 不明な点を推測で補わないでください。
- 一つの教材で扱う射程を広げすぎないでください。
- 学習順序が自然になるよう、基礎概念から順に並べてください。
- 調査に基づく教材では、確認に使った主要資料を最後に記録してください。

内容に合う範囲で、次を含めてください。

- その概念は何か。
- なぜ必要か。
- どのような仕組みで働くか。
- 判断に使える具体例。
- よくある誤解、境界、反例。
- 前後の概念や関連分野との関係。
- この教材だけでは判断できない範囲。

項目を機械的に埋める必要はありません。例や説明を増やすこと自体を目的にせず、学習目標の達成に必要なものだけを入れてください。

具体例を置いた場合は、条件を一つ変えた例でも同じ概念を使って判断できるようにします。問いを置く場合は、答えと理由を本文から追える形にします。

## 文体

- 短く自然な日本語を使ってください。
- 一文に複数の論点を詰め込みすぎないでください。
- 専門用語は初出時に簡潔に説明してください。
- 後で RSVP 用に分割しやすい文章にしてください。
- 英語直訳調や、意味の薄い接続表現を避けてください。

## 出力

Markdownで出力してください。

見出しを使い、内容のまとまりが分かる構造にしてください。

この原稿を人間がレビューした後、`prompts/lesson-generation.md` を使って RSVP JSON へ変換します。
