# RSVP教材生成用プロンプト

以下の指示は、調査結果からRSVP用教材JSONを作るときのテンプレートです。

---

与えられた調査結果を、RSVPで学習するための短い日本語教材へ再構成してください。

目的は、原文を高速表示することではなく、内容を理解しやすい短い意味のまとまりとして順番に提示することです。

## 内容

- 調査で確認できた事実と、解釈・推測を混同しないでください。
- 重要な条件、例外、限界を落とさないでください。
- 元資料の文章を長く転載せず、意味を保って独自の日本語へ書き換えてください。
- 長い引用は避けてください。
- 確認に使用した主要な資料を `sources` に記録してください。
- 情報が確認できない部分を推測で補わないでください。

## RSVP向け文章

- 1チャンクにつき、原則として1つの意味のまとまりにしてください。
- 日本語では、おおむね4〜14文字程度を目安にしつつ、自然な意味単位を優先してください。
- 助詞だけを独立させないでください。
- 固有名詞、数値、専門用語を不自然に分割しないでください。
- 一つのチャンクに複数の論点を詰め込まないでください。
- 前のチャンクを見返さなくても、流れを追いやすい語順にしてください。
- 文末や話題転換では `duration_multiplier` を1.2〜1.5程度にしてください。
- 短く予測しやすい接続部分は0.8〜1.0程度にできます。
- 難しい数値、固有名詞、専門用語は必要に応じて表示時間を長くしてください。

## 出力

`schema/lesson.schema.json` に適合するJSONだけを出力してください。

```json
{
  "schema_version": 1,
  "id": "kebab-case-id",
  "title": "教材タイトル",
  "topic": "分野",
  "summary": "教材の内容を1文で説明",
  "created_at": "YYYY-MM-DD",
  "base_duration_ms": 650,
  "sources": [
    {
      "title": "資料名",
      "url": "https://..."
    }
  ],
  "chunks": [
    {
      "text": "短い意味のまとまり",
      "duration_multiplier": 1.0
    }
  ]
}
```
