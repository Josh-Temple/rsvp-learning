# 公共DX・GovTechの入口

Status: SEED / 概要のみ

## 目的

この章は「公共DX・GovTech」の入口です。
現時点では網羅的な教材ではありません。
後続章を作るための骨格として置きます。

## 最初に押さえること

- 公共DXは、行政サービスと行政内部の業務をデジタルで改善する取り組みです
- 目的は、システム導入ではなく住民や職員への価値です
- 行政では、法令と制度が業務要件に強く影響します
- 調達では、発注者と事業者の役割分担を明確にします
- 標準化は、自治体ごとの過度な個別差を減らす狙いがあります
- データ連携では、形式だけでなく意味の一致が必要です
- クラウド利用では、可用性、セキュリティ、責任分界を考えます
- デジタル化しても、対面や紙が必要な利用者への配慮が必要です
- アクセシビリティは、多様な利用者がサービスを使えるようにする考え方です
- 制度改正への追随を、運用とシステムの両面で設計します
- 現場運用を理解しないシステム化は、別の負担を生むことがあります
- まずは、行政課題を業務要件とシステム要件へ分けて説明できることを目標にします
