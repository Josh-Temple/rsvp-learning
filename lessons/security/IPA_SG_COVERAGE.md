# IPA SG Ver.4.1 カバレッジ

確認日: 2026-09-27  
基準: IPA「情報セキュリティマネジメント試験（レベル2）シラバス Ver.4.1」

## 目的

この文書は試験対策表ではありません。

IPAの情報セキュリティマネジメント試験シラバスを、情報セキュリティを広く理解するための漏れ検出用チェックリストとして利用します。

シラバスの用語をすべて暗記対象にはしません。

一方で、セキュリティ理解に重要な概念が抜けている場合は、教材へ追加します。

## 現行基準

2026-09-27時点で、IPAが公開している情報セキュリティマネジメント試験の現行シラバスは Ver.4.1 です。

2027年度から予定されている新試験制度については、情報セキュリティマネジメント試験の新シラバス案はまだ「準備中」です。

新シラバスが公開されたら差分を確認します。

  https://www.ipa.go.jp/shiken/syllabus/gaiyou.html
- SG Ver.4.1  
  https://www.ipa.go.jp/shiken/syllabus/nl10bi0000007tch-att/syllabus_sg_ver4_1.pdf
- 2027年度新試験制度のシラバス案  
  https://www.ipa.go.jp/shiken/syllabus/henkou/2026/20260630.html

## 判定

- **収録済み**: 現在の教材で主要概念を説明している
- **一部収録**: 基礎はあるが、重要な下位概念が不足している
- **未収録**: 今後の教材に追加する
- **周辺分野**: SG範囲だが、情報セキュリティ教材では必要部分だけ扱う

## その他の分野

SGは、セキュリティそのもの以外にも広いIT基礎を含みます。

本教材では、すべてを独立した試験範囲として扱わず、セキュリティ理解に必要な部分だけを取り込みます。

| SG領域 | 方針 |
|---|---|
| システム構成・信頼性 | 冗長化、可用性、フェールセーフなど必要部分を扱う |
| データベース | アクセス制御、トランザクション、バックアップなど必要部分を扱う |
| ネットワーク | TCP/IP、IP、DNS、HTTP、メールなどを基礎章として扱う |
| プロジェクトマネジメント | 一般論は周辺分野。セキュリティリスク、調達、変更管理のみ必要に応じて扱う |
| サービスマネジメント | インシデント、問題、変更、可用性、継続、RTO/RPOを扱う |
| システム監査 | セキュリティ監査と内部統制を扱う |
| システム戦略・企画 | セキュリティ要件、調達、廃棄など必要部分を扱う |
| 一般的な企業活動 | セキュリティと直接関係する法務・契約・統制に限定する |

## 現時点の判断

第4回残差統合で、前回大きく残っていた認証、暗号、日本の制度、セキュアプロトコル、ネットワーク防御、メモリ安全性、法務の基礎を既存章へ統合しました。

IPA SG Ver.4.1を漏れ検出用チェックリストとして見た場合、現在大きく残る「一部収録」は主に次です。

1. 脅威・脆弱性のより細かな分類
2. マルウェアのより細かな種類
3. 攻撃手法の追加例
4. AI固有のセキュリティリスクの発展領域
5. 人的対策の詳細

これらは用語を網羅するだけで教材価値が上がるとは限りません。

今後は不足語彙を無制限に増やすより、現在の教材で主要概念同士の関係を理解できるかを優先します。

現段階を「主要領域を一通り説明できるDraft」と扱い、完全網羅とは扱いません。

次は、全原稿の重複、矛盾、学習順序、RSVP適性を横断的にレビューします。

詳細な教材構成は `CURRICULUM.md` を正本とします。
