# 同期・非同期・イベント・Queue

Status: DRAFT v0.1
Created: 2026-09-27

## 学習目標

処理を待つ同期方式と、Queueやイベントを使う非同期方式の違いを学びます。

## 本文

1. 同期処理では、相手の処理結果を待ちます
2. 処理の流れを理解しやすいことが利点です
3. ただし、相手が遅いと全体も待つことになります
4. 非同期処理では、依頼後に別の処理へ進めます
5. 時間のかかる処理を切り離せます
6. Queueは、処理要求を一時的に保存して受け渡します
7. 送信側と受信側を、時間的に分離できます
8. イベントは、何かが起きたことを表します
9. イベントを受けて別の処理を動かす設計があります
10. 非同期では、処理完了のタイミングが分かりにくくなります
11. 重複処理や順序入れ替わりも考える必要があります
12. 失敗したメッセージの扱いも設計します
13. 監視と追跡可能性が重要になります
14. 非同期化は、性能だけでなく依存を緩めるためにも使われます

## 注意

この章は基礎理解用です。
実務で判断するときは、対象システムの仕様、組織ルール、データの前提を別途確認します。
