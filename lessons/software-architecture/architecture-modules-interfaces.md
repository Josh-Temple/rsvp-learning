# モジュールとインターフェース

Status: DRAFT v0.1
Created: 2026-09-27

## 学習目標

システムを責務ごとに分け、部品同士の接点を明確にする基本を学びます。

## 本文

1. 大きなシステムは、役割ごとの部品へ分けて考えます
2. モジュールは、関連する責務をまとめた単位です
3. 一つのモジュールに多くの責務を詰め込みすぎないようにします
4. 責務が明確だと、変更範囲を限定しやすくなります
5. インターフェースは、部品同士の接点です
6. 何を受け取り、何を返すかを定めます
7. 内部実装を知らなくても利用できる形が望まれます
8. インターフェースを安定させると、内部変更の影響を減らせます
9. データ形式やエラー条件も、接点の一部です
10. 責務の境界が曖昧だと、同じ処理が複数箇所へ広がります
11. 共通処理を分ける場合も、責務を確認します
12. 細かく分けすぎると、連携が複雑になります
13. 分割には、適切な粒度が必要です
14. 設計では、責務と接点を説明できることが重要です

## 注意

この章は基礎理解用です。
実務で判断するときは、対象システムの仕様、組織ルール、データの前提を別途確認します。
