# ネットワークと端末の防御

Status: COMPLETE v0.1
Created: 2026-09-28

## 学習目標

ネットワークと端末の防御を多層で捉え、境界内部も無条件に信頼せず、侵入後の広がりを抑える考え方を学びます。

## 本文

1. 外部との境界だけを守れば十分でありません。
2. 内部からの攻撃も考えます。
3. 侵入後の広がりも考えます。
4. ネットワークを分ける方法があります。
5. 重要資源への経路を絞ります。
6. 必要な通信だけを許します。
7. 不要なポートを公開しません。
8. 通信元だけで信用しません。
9. 利用者と端末も確認します。
10. 端末の更新を続けます。
11. 古いソフトを放置しません。
12. 不要なソフトを減らします。
13. 管理者権限を常用しません。
14. マルウェア対策も一層です。
15. 単一の製品だけに依存しません。
16. ログを残して異常を見ます。
17. 通信量の変化も手掛かりです。
18. 不審な接続先も調べます。
19. 暗号化通信でも安全とは限りません。
20. 中身が悪意ある場合があります。
21. DNSも攻撃対象になり得ます。
22. 名前解決の異常も調べます。
23. 無線LANも管理対象です。
24. 持出し端末も管理対象です。
25. 紛失時の対策を用意します。
26. 遠隔停止も選択肢です。
27. 重要資源はさらに分離します。
28. 侵入を前提に被害を抑えます。
29. 境界内なら信頼できるでしょうか。
30. 場所だけでは判断できません。
31. 多層の防御で補い合います。
32. 監視と更新を続けます。

## 注意

この章は防御設計の基礎です。具体的なネットワーク構成、端末製品、検知ルールは環境ごとの脅威と要件に合わせて設計します。
