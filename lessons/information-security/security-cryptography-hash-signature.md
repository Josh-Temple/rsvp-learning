# 暗号・ハッシュ・デジタル署名

Status: COMPLETE v0.1
Created: 2026-09-28

## 学習目標

暗号化、ハッシュ、デジタル署名を目的別に区別し、暗号方式だけでなく鍵管理が重要な理由を説明できるようにします。

## 本文

1. 暗号化は内容を読みにくくします。
2. 復号には対応する鍵を使います。
3. 共通鍵方式では鍵を共有します。
4. 公開鍵方式は鍵の役割を分けます。
5. 方式ごとに用途が異なります。
6. 暗号化は改ざん検知と同じでありません。
7. ハッシュは要約値を作ります。
8. 元データが変わると値も変わります。
9. 改ざん検知に利用できます。
10. ハッシュは暗号化とは違います。
11. 通常は元へ戻す目的で使いません。
12. パスワード保存にも利用されます。
13. その場合は専用設計が必要です。
14. 単純なハッシュだけでは不十分です。
15. デジタル署名は署名者を確認します。
16. データの変更検知にも使えます。
17. 暗号化と署名は目的が違います。
18. 秘密にしたいなら暗号化を考えます。
19. 改ざんを見たいなら整合性を考えます。
20. 署名者を見たいなら署名を考えます。
21. 鍵が漏れると仕組みが崩れます。
22. 強い方式でも鍵管理が弱いと危険です。
23. 鍵の生成も管理対象です。
24. 保存場所も管理対象です。
25. 配布方法も管理対象です。
26. 更新と失効も管理します。
27. バックアップも慎重に扱います。
28. 鍵ごとに利用目的を分けます。
29. 暗号方式を自作しません。
30. 標準的な方式を適切に使います。
31. 暗号化済みなら安全でしょうか。
32. 鍵と利用方法まで確認します。

## 注意

この章は暗号技術の概念理解用です。具体的なアルゴリズム、鍵長、利用可否は用途と時点により変わるため、最新の標準・製品仕様を確認します。
