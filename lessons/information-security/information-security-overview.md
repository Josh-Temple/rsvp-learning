# 情報セキュリティ概観

Status: SEED / 概要のみ

## 目的

この章は「情報セキュリティ」の入口です。
現時点では網羅的な教材ではありません。
後続章を作るための骨格として置きます。

## 最初に押さえること

- 情報セキュリティは、情報とシステムを適切に守るための分野です
- 機密性は、許可された人だけが情報へアクセスできる状態です
- 完全性は、情報が正確で不正に変更されていない状態です
- 可用性は、必要なときに利用できる状態です
- 脅威は、損害を起こす原因になり得るものです
- 脆弱性は、攻撃や事故につながる弱点です
- リスクは、脅威と脆弱性と影響を踏まえて考えます
- 認証と認可は、アクセス制御の基本です
- 暗号は、通信や保存データを守る重要な技術です
- ネットワーク防御だけでなく、人と運用の対策も必要です
- インシデントでは、検知、封じ込め、復旧、再発防止を考えます
- この章は入口であり、IPA範囲を扱う本編は別章で拡張します
