# システム開発の全体像

Status: SEED / 概要のみ

## 目的

この章は「システム開発」の入口です。
現時点では網羅的な教材ではありません。
後続章を作るための骨格として置きます。

## 最初に押さえること

- システム開発は、実装だけではありません
- 最初に、解決したい業務課題を整理します
- 企画では、目的と投資範囲を決めます
- 要件定義では、実現すべき条件を明確にします
- 設計では、要件を実装可能な構造へ落とします
- 実装では、設計をコードや設定として形にします
- テストでは、期待どおり動くかを確認します
- 移行では、旧業務から新しい仕組みへ切り替えます
- 運用保守では、障害対応と継続改善を行います
- WaterfallとAgileは、進め方の違いとして理解します
- まずは、各工程の目的と成果物を説明できることを目標にします

## 次に深掘りする項目

- 企画と費用対効果
- 基本設計と詳細設計
- テスト工程
- 移行計画
- WaterfallとAgile

## 編集方針

詳細化するときは、公式資料・一次資料を優先して確認します。
確認していない具体的な数値、制度要件、製品仕様は推測で補いません。
通常文として内容レビューした後に、RSVP向けの短い意味単位へ変換します。
