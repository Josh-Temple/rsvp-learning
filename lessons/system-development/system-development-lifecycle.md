# 開発ライフサイクル

Status: COMPLETE v0.1
Created: 2026-09-27

## 学習目標

企画から運用保守まで、システム開発の工程と各工程の目的を学びます。

## 本文

1. システム開発は、複数の工程で進みます
2. 企画では、解くべき課題と投資目的を整理します
3. 要件定義では、実現すべき条件を決めます
4. 設計では、要件を実装可能な構造へ落とします
5. 実装では、コードや設定として形にします
6. テストでは、期待どおり動くか確認します
7. 移行では、旧環境から新環境へ切り替えます
8. リリース後は、運用と保守が始まります
9. 障害対応だけが、運用ではありません
10. 監視、問い合わせ、改善も運用に含まれます
11. 前工程の曖昧さは、後工程で大きな手戻りになり得ます
12. 一方で、すべてを最初に確定できるとは限りません
13. 工程ごとの目的と成果物を理解することが重要です
14. 全体像を持つと、自分の担当の位置づけが見えます

## 次に確認したいこと
