# Git・GitHub・CI/CDの入口

Status: SEED / 概要のみ

## 目的

この章は「Git・GitHub・CI/CD」の入口です。
現時点では網羅的な教材ではありません。
後続章を作るための骨格として置きます。

## 最初に押さえること

- Gitは、ファイルの変更履歴を管理する仕組みです
- commitは、変更を一つの履歴として記録します
- branchは、作業の流れを分けるために使います
- mergeは、分かれた変更を統合します
- GitHubでは、Pull Requestで変更内容をレビューできます
- Issueは、課題や作業を記録するために使えます
- CIは、変更のたびにテストや検査を自動実行する考え方です
- CDは、成果物を継続的に配布またはデプロイする考え方です
- GitHub Actionsは、GitHub上で自動処理を実行できます
- 環境ごとに設定や秘密情報を分離します
- デプロイ後には、動作確認とrollback経路を考えます
- まずは、変更が本番へ届くまでの流れを説明できることを目標にします
