# リレーショナルモデルの基本

Status: COMPLETE v0.1
Created: 2026-09-27

## 学習目標

テーブル、行、列、主キー、外部キーなどリレーショナルデータベースの基本構造を学びます。

## 本文

1. リレーショナルデータベースは、表の関係としてデータを扱います
2. 表を、テーブルと呼びます
3. 一件分のデータを、行として表します
4. 属性を、列として表します
5. 主キーは、行を一意に識別します
6. 同じ主キーを、複数の行で使わないようにします
7. 外部キーは、別のテーブルの行との関係を表します
8. 例えば、注文は顧客IDを持つことがあります
9. 顧客情報を毎回注文表へ重複保存する必要はありません
10. 関係を使うことで、データを分けて管理できます
11. NULLは、値が不明または未設定であることを表し、ゼロや空文字とは別に扱われます
12. データ型は、列に入る値の種類を定めます
13. 制約は、データの整合性を守るために使われます
14. 良いデータ設計は、業務上の関係を正しく表します
15. 顧客表に顧客IDと氏名、注文表に注文IDと顧客IDを置きます。
16. 顧客IDは顧客表の行を識別する主キーです。
17. 注文表の顧客IDは、どの顧客の注文かを示す外部キーです。
18. 一人の顧客に注文が二件あれば、注文表には同じ顧客IDが二行現れます。
19. 注文IDだけで顧客名を探すには、二つの表の関係をたどります。
