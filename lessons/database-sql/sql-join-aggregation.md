# JOINと集計

Status: COMPLETE v0.1
Created: 2026-09-27

## 学習目標

複数テーブルの結合とGROUP BYによる集計の基本を学びます。

## 本文

1. JOINは、複数のテーブルを関連づけて取得する操作です
2. INNER JOINは、両方に一致する行を取得します
3. LEFT JOINは、左側の行を残しながら結合します
4. 結合条件には、主キーと外部キーを使うことが多いです
5. 結合条件を誤ると、行数が想定以上に増えることがあります
6. まず、テーブルの粒度を確認します
7. COUNTは、件数を数えます
8. SUMは、合計を求めます
9. AVGは、平均を求めます
10. GROUP BYは、グループ単位で集計します
11. HAVINGは、集計後の結果を条件で絞ります
12. 集計値だけでなく、分母の定義も確認します
13. JOINとGROUP BYを組み合わせると、多くの業務集計ができます
14. 結果が正しいか、小さな例で検算する習慣が重要です
15. 顧客表にAとB、注文表にAの注文二件だけがあるとします。
16. 顧客IDでINNER JOINすると、Aの注文二行が得られます。
17. 顧客表を左にしたLEFT JOINなら、注文のないBも残ります。
18. 結合後の行を数えると顧客数ではなく注文数になる場合があります。
19. 何を一件と数えるかを決め、顧客別の合計と注文数を分けて確認します。
