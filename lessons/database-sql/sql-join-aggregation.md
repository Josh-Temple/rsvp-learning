# JOINと集計

Status: COMPLETE v0.1
Created: 2026-09-27

## 学習目標

複数テーブルの結合とGROUP BYによる集計の基本を学びます。

## 本文

1. 顧客表にAとB、注文表にAの注文二件だけがあるとします。
2. 顧客IDでINNER JOINすると、Aの注文二行が得られます。
3. JOINは、複数のテーブルを関連づけて取得する操作です
4. INNER JOINは、両方に一致する行を取得します
5. LEFT JOINは、左側の行を残しながら結合します
6. 結合条件には、主キーと外部キーを使うことが多いです
7. 結合条件を誤ると、行数が想定以上に増えることがあります
8. まず、テーブルの粒度を確認します
9. COUNTは、件数を数えます
10. SUMは、合計を求めます
11. AVGは、平均を求めます
12. GROUP BYは、グループ単位で集計します
13. 左結合でBの注文欄が空の行も残るため、結果の行数と注文の件数は一致しません。
14. HAVINGは、集計後の結果を条件で絞ります
15. 集計値だけでなく、分母の定義も確認します
16. JOINとGROUP BYを組み合わせると、多くの業務集計ができます
17. 結果が正しいか、小さな例で検算する習慣が重要です
18. 顧客表を左にしたLEFT JOINなら、Aの二行と注文のないBの一行で計三行です。
19. この結果のCOUNT(*)は三、COUNT(注文ID)は二です。
20. 顧客IDでGROUP BYし、注文IDを数えると、Aは二件、Bは零件になります。
21. 集計前に行の粒度とNULLを数えるかを決めないと、正しい構文でも答えを誤ります。
