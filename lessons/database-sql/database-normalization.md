# 正規化の基本

Status: COMPLETE v0.1
Created: 2026-09-27

## 学習目標

データの重複や更新時の矛盾を減らすための正規化の考え方を学びます。

## 本文

1. 正規化は、データ構造を整理する考え方です
2. 目的の一つは、不要な重複を減らすことです
3. 同じ情報を何度も保存すると、更新漏れが起きやすくなります
4. 一部だけ更新されると、矛盾したデータが残ります
5. これを、更新異常と呼ぶことがあります
6. 第一正規形では、各列に一つの値を持たせ、同じ行へ繰り返し項目を詰め込みません
7. 第二正規形では、第一正規形を満たし、複数列の主キーの一部だけで決まる属性を分けます
8. 第三正規形では、非キー属性が別の非キー属性に依存しないよう整理します
9. 厳密な定義は、後で段階的に学べば十分です
10. 最初は、何の事実をどのテーブルが持つかを考えます
11. 一つの事実を、複数箇所で重複管理しないようにします
12. ただし、性能や分析目的で意図的に重複させる場合もあります
13. これを非正規化と呼ぶことがあります
14. 正規化は、目的ではなく整合性を保つ手段です
