# データベースとSQLの入口

Status: SEED / 概要のみ

## 目的

この章は「データベース・SQL」の入口です。
現時点では網羅的な教材ではありません。
後続章を作るための骨格として置きます。

## 最初に押さえること

- データベースは、情報を継続的に管理する仕組みです
- 表形式のデータを扱う代表例が、リレーショナルデータベースです
- テーブルは、行と列でデータを表します
- 主キーは、行を一意に識別します
- 外部キーは、テーブル同士の関係を表します
- 正規化は、重複や更新時の矛盾を減らす考え方です
- SQLは、データベースへ問い合わせるための言語です
- SELECTで取得し、WHEREで絞り込みます
- JOINで複数のテーブルを結合します
- GROUP BYで集計し、Window関数で行同士を比較できます
- トランザクションは、複数処理の整合性を守ります
- 最初は、データ構造を読み、必要なSQLを書けることを目標にします

- 正規化
