# SELECTと絞り込み

Status: DRAFT v0.1
Created: 2026-09-27

## 学習目標

SQLでデータを取得し、条件で絞り込み、並べ替える基本操作を学びます。

## 本文

1. SELECTは、データを取得するSQLです
2. FROMで、対象のテーブルを指定します
3. 必要な列だけを選ぶことができます
4. WHEREで、条件に合う行を絞り込みます
5. 等しい、より大きい、含む、などの条件を使えます
6. 複数条件は、ANDやORで組み合わせます
7. NULLの判定には、IS NULLを使います
8. ORDER BYで、結果を並べ替えます
9. ASCは昇順、DESCは降順です
10. DISTINCTは、重複した結果を除くために使えます
11. LIMITなどで、取得件数を制限できるDBもあります
12. 条件を書いたら、意図した行だけ取れているか確認します
13. 大量データでは、不要な全件取得を避けます
14. SQLは、データ構造を理解して書くことが重要です
