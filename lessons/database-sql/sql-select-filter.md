# SELECTと絞り込み

Status: COMPLETE v0.1
Created: 2026-09-27

## 学習目標

SQLでデータを取得し、条件で絞り込み、並べ替える基本操作を学びます。

## 本文

1. 注文表に金額1000円と3000円の二行があるとします。
2. WHERE 金額 >= 2000 なら後者だけが残ります。
3. SELECTは、データを取得するSQLです
4. FROMで、対象のテーブルを指定します
5. 必要な列だけを選ぶことができます
6. WHEREで、条件に合う行を絞り込みます
7. 等しい、より大きい、含む、などの条件を使えます
8. 複数条件は、ANDやORで組み合わせます
9. NULLの判定には、IS NULLを使います
10. ORDER BYで、結果を並べ替えます
11. ASCは昇順、DESCは降順です
12. DISTINCTは、重複した結果を除くために使えます
13. WHEREは条件に合う行を選び、SELECTは表示する列を決めるため、二つの役割を分けて読めます。
14. LIMITなどで、取得件数を制限できるDBもあります
15. 条件を書いたら、意図した行だけ取れているか確認します
16. 大量データでは、不要な全件取得を避けます
17. SQLは、データ構造を理解して書くことが重要です
18. SELECTで表示する列を指定しても、条件に合う行の判断は変わりません。
19. NULLを含む列は通常の等号比較だけでは期待した結果にならないため扱いを確認します。
20. 少数の行で結果を予想し、実際のクエリと照らします。
21. 条件にNULLが含まれると単純な大小比較だけでは選ばれないため、欠損の扱いも指定します。
22. 金額が未入力の行を調べるとします。
23. 金額が二千円未満という条件では選べません。
24. 欠損を探すなら、NULL用の条件を使います。
25. 結果がないことは行がない証拠ですか。
26. 条件から除かれた行も確認します。
