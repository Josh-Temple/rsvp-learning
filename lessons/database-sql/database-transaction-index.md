# トランザクションとインデックス

Status: DRAFT v0.1
Created: 2026-09-27

## 学習目標

データ更新の整合性を守るトランザクションと、検索性能を支えるインデックスの基本を学びます。

## 本文

1. トランザクションは、複数の処理を一まとまりとして扱います
2. 途中で失敗した場合、処理を取り消すことがあります
3. これをrollbackと呼びます
4. すべて成功したら、変更を確定します
5. これをcommitと呼びます
6. ACIDは、トランザクションの代表的な性質を表します
7. Atomicityは、処理を全部成功か全部失敗にします
8. Consistencyは、整合性を保つことに関係します
9. Isolationは、同時実行の影響を制御します
10. Durabilityは、確定した結果を保持する性質です
11. インデックスは、検索を高速化するための構造です
12. ただし、インデックスにも保存容量と更新コストがあります
13. すべての列へ付ければ良いわけではありません
14. 整合性と性能は、用途に応じて設計します
