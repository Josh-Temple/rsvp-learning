# コスト・速度・セキュリティ

Status: COMPLETE v0.1
Created: 2026-09-27

## 学習目標

生成AIアプリを実運用する際のコスト、レイテンシ、データ保護、障害時設計を学びます。

## 本文

1. 長い資料を毎回AIへ渡すと、入力が増え、費用と応答時間に影響します。
2. 資料の一部を検索して渡す場合も、検索時間と検索の誤りが加わります。
3. 生成AIアプリでは、品質だけを見ても不十分です
4. 利用量が増えると、推論コストも増えることがあります
5. 不要に長い入力や出力は、コストへ影響します
6. 応答速度も、利用体験へ影響します
7. 複数のモデルやツールを呼ぶと、待ち時間が増えることがあります
8. 重要度に応じて、モデルや処理方法を選びます
9. 入力データには、個人情報や機密情報が含まれる場合があります
10. 送信してよい情報のルールを明確にします
11. 外部ツールへ渡すデータも確認します
12. Prompt Injectionなど、AI特有の攻撃も考慮します
13. 入力資料を短くすると費用や時間を減らせる場合がありますが、必要な根拠まで落とせば回答品質が下がります。
14. 失敗時に、安全側へ倒れる設計が必要です
15. 外部サービス障害時の代替動作も考えます
16. ログには、必要な情報を残しつつ秘密情報を避けます
17. 実運用では、品質、費用、速度、安全性のバランスを取ります
18. 機密の申請情報を含むなら、送信先と保存の扱いを先に確認します。
19. 短い質問と長い質問を分けて測り、平均だけでなく遅い応答も見ます。
20. 品質、費用、待ち時間を同じ条件で比較します。
21. 送信する情報と障害時の動作も含め、一件の要求を最後まで追って比較します。

## 注意

この章は基礎理解用です。
特定クラウド事業者、特定LLM、特定フレームワークの最新仕様を説明する教材ではありません。
製品固有の仕様や現在の制約は、利用時点の公式資料で確認します。
