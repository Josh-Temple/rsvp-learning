## 目的

現時点では網羅的な教材ではありません。
後続章を作るための骨格として置きます。

## 最初に押さえること

- クラウドは、計算資源をネットワーク経由で利用する形態です
- 必要な資源を、必要に応じて増減できます
- IaaSは、仮想マシンなど基盤に近い資源を提供します
- PaaSは、アプリ実行環境をより管理された形で提供します
- SaaSは、完成したソフトウェアをサービスとして利用します
- IAMは、誰が何へアクセスできるかを管理します
- ネットワーク設計は、通信経路と境界を決めます
- ストレージとデータベースは、データの性質に応じて選びます
- Serverlessは、サーバー管理を減らして処理を実行する選択肢です
- 可用性では、障害が起きてもサービスを継続できる構成を考えます
- 監視とログは、異常の検知と原因調査に必要です
- 最初は、Azureを軸に各サービスの役割を理解します
