# クラウドネットワークの基本

Status: DRAFT v0.1
Created: 2026-09-27

## 学習目標

仮想ネットワーク、公開・非公開の境界、通信制御の基本を学びます。

## 本文

1. クラウドでも、ネットワークの基本は変わりません
2. システム同士は、ネットワークを通じて通信します
3. 仮想ネットワークは、クラウド上に論理的な通信範囲を作ります
4. サブネットで、ネットワークを複数の範囲へ分けられます
5. 外部公開が必要な部分と、内部だけで使う部分を分けます
6. データベースを直接インターネットへ公開しない設計が一般的です
7. FirewallやSecurity Groupなどで通信を制御します
8. 必要な宛先とポートだけを許可します
9. DNSは、名前と接続先を対応づけます
10. Load Balancerは、複数の処理先へ通信を分散します
11. 通信経路を複雑にすると、障害調査も難しくなります
12. ネットワーク設計では、到達性と安全性を両方考えます
13. 通信ログは、問題調査に役立ちます
14. まずは、利用者からアプリ、データベースまでの経路を説明できるようにします

## 注意

この章は基礎理解用です。
特定クラウド事業者、特定LLM、特定フレームワークの最新仕様を説明する教材ではありません。
製品固有の仕様や現在の制約は、利用時点の公式資料で確認します。
