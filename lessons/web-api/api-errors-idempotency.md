# エラー処理と冪等性

Status: COMPLETE v0.1
Created: 2026-09-27

## 学習目標

APIの失敗を扱うためのStatus Code、Retry、冪等性の基本を学びます。

## 本文

1. API通信は、常に成功するとは限りません
2. 入力が不正な場合があります
3. 権限が不足している場合があります
4. 対象データが存在しない場合があります
5. サーバー内部で失敗する場合もあります
6. HTTP Status Codeは、失敗の種類を伝えるために使われます
7. 4xxは、要求側に原因がある場合に使われることが多いです
8. 5xxは、サーバー側の失敗を表すことが多いです
9. 失敗時に、何でもRetryすれば良いわけではありません
10. 同じ要求を再送すると、二重登録が起こることがあります
11. 冪等性は、同じ要求を何度行っても、意図した効果が一度のときと同じになる性質です
12. GETは、通常は副作用を持たないように設計します
13. 重要な登録処理では、Idempotency Keyを使う設計もあります
14. エラー処理は、正常処理と同じくらい重要です
