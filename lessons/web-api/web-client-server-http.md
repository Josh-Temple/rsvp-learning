# クライアント・サーバーとHTTP

Status: COMPLETE v0.1
Created: 2026-09-27

## 学習目標

ブラウザなどのクライアントとサーバーがHTTPで通信する基本構造を学びます。

## 本文

1. Webシステムでは、クライアントとサーバーが通信します
2. ブラウザは、代表的なクライアントです
3. サーバーは、要求を受けて処理し、応答を返します
4. HTTPは、Webで広く使われる通信の仕組みです
5. クライアントは、HTTP Requestを送ります
6. サーバーは、HTTP Responseを返します
7. URLは、アクセスする資源の場所を示します
8. GETは、情報取得に使われることが多いです
9. POSTは、新しい処理や登録に使われることが多いです
10. PUTやPATCHは、更新に使われることがあります
11. DELETEは、削除を表すために使われます
12. Status Codeは、処理結果の種類を示します
13. Headerは、通信に関する追加情報を持ちます
14. Bodyは、送受信するデータ本体を持つことがあります
