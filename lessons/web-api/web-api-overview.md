Status: SEED / 概要のみ

## 目的

この章は「API・Webシステム」の入口です。
現時点では網羅的な教材ではありません。
後続章を作るための骨格として置きます。

## 最初に押さえること

- Webシステムは、複数の役割が連携して動きます
- ブラウザなどのクライアントが、サーバーへ要求を送ります
- HTTPは、その通信で広く使われる仕組みです
- Requestは要求、Responseは応答です
- GETやPOSTなどのHTTPメソッドは、操作の種類を表します
- APIは、ソフトウェア同士が機能を利用するための接点です
- REST APIでは、HTTPを使って資源を操作する設計がよく使われます
- JSONは、APIでデータ交換によく使われる形式です
- 認証は誰かを確認し、認可は何を許すかを決めます
- Webhookは、出来事が起きた側から通知する仕組みです
- まずは、画面、API、サーバー、データベースの関係を説明できることを目標にします
