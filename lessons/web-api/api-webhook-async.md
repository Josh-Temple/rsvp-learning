# Webhookと非同期処理

Status: DRAFT v0.1
Created: 2026-09-27

## 学習目標

イベント通知、Webhook、Queueなどを使う非同期処理の基本を学びます。

## 本文

1. 同期処理では、処理結果を待ってから次へ進みます
2. 非同期処理では、結果を待たずに別の処理へ進めます
3. 時間のかかる処理では、非同期が有効な場合があります
4. Webhookは、出来事が起きた側から通知する仕組みです
5. 例えば、決済完了後に通知を送ることができます
6. 通知を受けるURLを、事前に登録します
7. Webhookは、同じ通知が複数回来る可能性も考えます
8. そのため、受信側には冪等性が重要です
9. Queueは、処理要求を一時的にためる仕組みです
10. 送信側と処理側を、時間的に分離できます
11. 再試行や失敗処理を設計しやすくなります
12. 一方で、処理状況が見えにくくなることがあります
13. 監視とログが、より重要になります
14. 非同期化は、複雑性と引き換えに柔軟性を得る設計です
