# REST APIとJSON

Status: COMPLETE v0.1
Created: 2026-09-27

## 学習目標

REST APIの基本的な考え方と、データ交換形式JSONの読み方を学びます。

## 本文

1. APIは、ソフトウェア同士の接点です
2. RESTは、Web APIで広く使われる設計上の考え方です
3. 資源を、URLで表すことがあります
4. HTTPメソッドで、操作の種類を表します
5. 例えば、顧客一覧をGETで取得できます
6. 新しい顧客をPOSTで登録する設計もあります
7. URLとHTTPメソッドを使うだけで、RESTの原則をすべて満たすとは限りません
8. 名前より、一貫したAPI設計が重要です
9. JSONは、データ交換でよく使われる形式です
10. オブジェクトは、キーと値の組で表します
11. 配列は、複数の値を順番に持ちます
12. 文字列、数値、真偽値、nullなどを扱えます
13. API仕様では、入力と出力の形を明確にします
14. エラー時の応答も、API仕様の一部です
15. 申請一覧を取得する要求を送ると、サーバーはJSONで申請IDと状態を返すとします。
16. 新規作成では必要な項目を送信し、成功時は作られた資源を示します。
17. 見つからないIDと権限のないIDは扱いが違います。
18. HTTPの方法、URL、状態コード、応答の形を合わせて確認します。
19. JSONの形だけで操作の意味は決まりません。
