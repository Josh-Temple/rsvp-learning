# 仮説検定・p値・効果量

Status: COMPLETE v0.1
Created: 2026-09-27

## 学習目標

受付方法の比較例から、p値の意味、効果の大きさ、検定だけでは決められない理由を学びます。

## 本文

1. 新しい受付方法で、処理時間が短くなったかを調べるとします。
2. 帰無仮説は、平均処理時間に差がないなどの基準です。
3. 検定では、帰無仮説と計算の前提を置きます。
4. p値は、その前提の下で、観測結果以上に極端な
5. 結果が出る確率です。
6. 帰無仮説が正しい確率ではありません。
7. 例えば、p値が〇点〇四だったとします。
8. 〇点〇五より小さいだけで、改善が大きいとは言えません。
9. 一万件なら、一件当たりの小さな差も検出され得ます。
10. 処理時間が平均で〇点一分縮んでも、運用価値は別に判断します。
11. 差の大きさを、効果量として併記します。
12. 推定した差の信頼区間も、どの程度不確かな結果かを示します。
13. 一方、p値が大きいことは、差がゼロの証明ではありません。
14. 件数が少なければ、重要な差を見逃すこともあります。
15. 後から多くの指標を試し、小さいp値だけを選ぶと誤解を招きます。
16. 何を比べるかと、重要な差の大きさを先に定めます。
17. 担当者の熟練度や案件の難しさに偏りがあれば、比較も歪みます。
18. 統計的な有意性だけで、導入を決めません。
19. 費用、負担、公平性なども結果と併せて確認します。
20. 結論には、差の大きさと不確実性、比較条件を添えます。

## 注意

この章は基礎理解用です。
実務で判断するときは、対象システムの仕様、組織ルール、データの前提を別途確認します。
