# 仮説検定・p値・効果量

Status: COMPLETE v0.1
Created: 2026-09-27

## 学習目標

仮説検定の前提、p値、効果量、信頼区間、検出力、多重比較、交絡を区別し、統計的有意性と実務上の判断を分けて考えます。

## 本文

1. 新しい受付方法を比べるとします。
2. 平均処理時間の差を調べます。
3. 帰無仮説を基準として置きます。
4. 検定には計算上の前提があります。
5. p値はその前提の下で読みます。
6. 観測以上に極端な結果の確率です。
7. 帰無仮説が正しい確率ではありません。
8. 小さいp値だけで効果は分かりません。
9. 件数が多いと小差も検出されます。
10. 平均〇点一分の差かもしれません。
11. 実務上重要かは別に判断します。
12. 差の大きさを効果量で見ます。
13. 信頼区間も不確実性の手掛かりです。
14. p値が大きくても差ゼロとは限りません。
15. 件数不足で見逃すことがあります。
16. 検出したい差と必要件数を考えます。
17. 多くの指標を試すと注意が要ります。
18. 偶然の小さいp値を拾いやすくなります。
19. 主な比較を事前に定めます。
20. 結果を見て基準を変えないようにします。
21. 比較条件の偏りにも注意します。
22. 担当者の熟練度が違うかもしれません。
23. 案件の難しさも違うかもしれません。
24. 観察データでは交絡を検討します。
25. 統計的有意性だけで導入を決めません。
26. 費用や負担も合わせて見ます。
27. 公平性や副作用も確認します。
28. 結論には差と不確実性を添えます。
29. 比較条件も一緒に示します。
30. 五指標で一つだけ有意とします。
31. 後から選んだ結果か確認します。
32. 一つのp値だけで採用でしょうか。
33. 効果量と比較回数も見ます。
34. 再現するか別データでも確かめます。

## 注意

この章は基礎理解用です。実際の検定法、必要標本数、因果推論はデータ構造と分析目的に応じて確認します。
