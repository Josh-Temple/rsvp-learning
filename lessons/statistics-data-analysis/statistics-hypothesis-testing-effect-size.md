# 仮説検定・p値・効果量

Status: COMPLETE v0.1
Created: 2026-09-27

## 学習目標

仮説検定の考え方、p値の読み方、効果量の重要性を学びます。

## 本文

1. 仮説検定は、観測された差を統計的に検討する方法です
2. 帰無仮説は、差がないなどの基準となる仮説です
3. p値は、帰無仮説と検定の前提が正しいとしたとき、観測結果以上に極端な結果が得られる確率です
4. p値は、帰無仮説が正しい確率を示すものではありません
5. p値が小さくても、差が大きいとは限りません
6. 標本数が大きいと、小さな差でも検出されることがあります
7. そのため、効果量も確認します
8. 効果量は、差や関係の大きさを表します
9. 信頼区間を合わせて見ると、不確実性も分かります
10. 有意差がないことは、差がない証明とは限りません
11. 検出力が不足している場合もあります
12. 多数の検定を行うと、偶然の有意差が増えます
13. 分析前に、何を検定するか決めることが重要です
14. 統計的有意性と実務上の重要性を分けて考えます

## 注意

この章は基礎理解用です。
実務で判断するときは、対象システムの仕様、組織ルール、データの前提を別途確認します。
