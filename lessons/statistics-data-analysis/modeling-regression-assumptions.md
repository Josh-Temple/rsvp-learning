# 回帰の前提・残差・診断

Status: COMPLETE v0.1
Created: 2026-10-31

## 学習目標

残差の意味を説明し、形・広がり・時間順の偏りから確認すべき問題を挙げられる。モデルを当てはめる計算と、その推論に必要な前提を区別できる。

## 本文

1. 作業件数から一日の処理時間を予測する回帰を
2. 作ったとします。
3. 過去のデータへの当てはまりがよくても、
4. 必要な性質をすべて確かめたことにはなりません。
5. 診断は、モデルがどこで現象を捉え損ねているかを
6. 調べる工程です。
7. 以下は架空の作業記録を想定します。
8. 残差は、観測値から、
9. その観測条件でのモデル値を引いたものです。
10. 予測が八十分、観測が九十分なら、
11. 残差はプラス十分です。
12. 式では `残差＝観測値−モデル値` で、
13. 正なら実際のほうが長く、
14. 負なら短かったと読めます。
15. 横軸を予測値、縦軸を残差にした図で、
16. 中央付近は負、両端は正という曲がり方があれば、
17. 直線だけでは平均的な形を
18. 捉え切れていない可能性があります。
19. 件数が多いと急に時間が増える、
20. という仕組みがないか考えます。
21. 予測値が大きいほど残差の幅が広がるなら、
22. 誤差の分散が一定という仮定に疑いが生じます。
23. 時間順に正の残差が続くなら、
24. 同じ日の混雑や設備不調など、
25. 観測間の関連を調べます。
26. これらの図は問題の手掛かりで、
27. 原因を一意に決める証拠ではありません。
28. 一つの極端な記録で係数が大きく変わる場合も
29. あります。
30. 入力誤りか、珍しいが実在する条件かを確認し、
31. 都合のよさで削除しません。
32. 含む場合と含まない場合の結果がどれほど違うかも
33. 判断材料になります。
34. 指定した説明変数の下で平均の形が適切で、
35. 誤差の平均が零になるという条件は、
36. 係数の解釈を支えます。
37. 切片を含む最小二乗回帰で、
38. 標本内の残差合計が零になっただけでは、
39. この条件を母集団について確認したことには
40. なりません。
41. 誤差の独立性や一定の分散は、
42. 通常の標準誤差の計算に関係します。
43. 分散が不均一なら、
44. そのことだけで係数が必ず偏るわけでは
45. ありませんが、通常の区間や検定を
46. そのまま信じるのは適切でない場合があります。
47. 設計と目的に合う方法を検討します。
48. 誤差の正規性は、小標本で通常の検定や区間を
49. 厳密に扱う際などに重要です。
50. 説明変数や目的変数自体が正規分布でなければ、
51. 最小二乗の係数を計算できないという意味では
52. ありません。
53. 件数と時間の関係が設備ごとに異なるなら、
54. 設備によって傾きが変わる交互作用を考えます。
55. 測定機器が件数を誤記していれば、
56. 説明変数の誤差が係数を歪めることもあります。
57. 観測した一日十件から百件の関係を、
58. 千件の日へ延ばすのは外挿です。
59. 高い決定係数、つまり標本内の変動を多く説明し

61. なりません。
62. 残差、測定方法、利用範囲を併せて診断し、
63. 新しい対象での予測検証へ進みます。
