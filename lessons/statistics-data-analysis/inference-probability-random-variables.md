# 確率・確率変数・分布

Status: COMPLETE v0.1
Created: 2026-10-31

## 学習目標

事象と確率変数を区別できる。条件付き確率の向きを確かめ、独立性や一定の確率を仮定した計算を説明できる。離散分布と連続分布の基本的な読み方を区別できる。

## 本文

1. 検品前には、次の製品が不良かどうかは
2. 分かりません。
3. 「不良になる」は事象、
4. つまり起こるかどうかを考える出来事です。
5. 確率は、その出来事の起こりやすさを零から一で
6. 表します。
7. 二十パーセントは〇点二です。
8. 以下は学習用に仮定した確率や件数で、
9. 実際の品質データではありません。
10. 確率〇点二だから、
11. 五回試すたび必ず一回起きるわけではありません。
12. 同じ条件で独立な試行を繰り返しても、
13. 短い区間の回数は変動します。
14. 実際の過去の割合を、
15. 条件が違う次の製品の確率と見なしてよいかも別に
16. 検討します。
17. 出荷百件のうち、急ぎの出荷が四十件、
18. 遅延した出荷が二十件、
19. 両方に該当するものが十件だったとします。
20. この百件から一件を等しい確率で選ぶ場面を
21. 考えます。
22. 急ぎだったという条件の下で遅延した確率は、
23. 四十件のうち十件なので二十五パーセントです。
24. 遅延したという条件の下で急ぎだった確率は、
25. 二十件のうち十件で五十パーセントです。
26. 両方に該当する件数が同じでも、
27. 条件を逆にすると分母が変わります。
28. 式では「Aの確率、
29. Bという条件付き」を P(A|B) と
30. 書き、AとBの両方が起きる確率を、
31. Bが起きる確率で割ります。
32. この式を使うには、
33. Bの確率が零より大きいことが必要です。
34. 式の縦線は「Bという条件で」と読みます。
35. 独立とは、一方が起きたという情報によって、
36. もう一方の確率が変わらない関係です。
37. 独立な試行で、不良確率が毎回〇点二なら、
38. 三個とも不良でない確率は、
39. 〇点八を三回掛けた〇点五一二です。
40. 少なくとも一個が不良である確率は、
41. 一からこれを引き、〇点四八八になります。
42. 同じ不調な機械から続けて作った製品など、
43. 結果が関連する場合には、
44. この掛け算をそのまま使えません。
45. 各回の不良割合が二十パーセントという情報だけで
46. は、三個の結果の関係までは決まらないためです。
47. 確率変数は、偶然の結果に応じて
48. 値が決まる数量です。
49. 三個の不良個数なら、零、一、二、三を取り得ます。
50. 各値の確率をまとめたものが、その確率分布です。
51. 先ほどのように独立で確率が一定の二択の試行を
52. 固定回数繰り返すとき、
53. 不良個数は二項分布で表せます。
54. その期待値は、試行回数と不良確率を
55. 掛けた〇点六個です。
56. 期待値は同じ条件の集計を繰り返したときの平均を
57. 表すもので、一回の検品で〇点六個の不良が出ると
58. いう意味ではありません。
59. 一方、理想化した重量などの連続的な量は、
60. 区間に入る確率で考えます。
61. 連続分布の確率密度は、
62. 曲線の高さそのものではなく、
63. 区間の面積が確率に対応します。
64. 左右対称の釣鐘形をした正規分布は代表例ですが、
65. あらゆる測定値が正規分布に従うわけでは
66. ありません。
67. 分布を選ぶときには、値が個数か連続量か、
68. 試行が独立か、確率が一定かを確認します。
69. 計算を始める前に、
70. 置いた条件を言葉で示すことが、
71. 確率を実務へ使う入口です。

## 注意

この章の数値・事例は学習用の架空例です。利用時は抽出・独立性・測定・時点などの前提条件を再確認してください。
