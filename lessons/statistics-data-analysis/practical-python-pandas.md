## 画面確認用の補助コード・出力（読み上げ本文とは別）

```python
import pandas as pd

df = pd.DataFrame({
    "受付ID": [1, 2, 3, 4],
    "部署": ["A", "A", "B", None],
})
counts = df.groupby("部署", dropna=False).size()
print("入力行数:", len(df))
print("集計行数の合計:", int(counts.sum()))
print("部署未記入:", int(counts[counts.index.isna()].iloc[0]))
```

```text
入力行数: 4
集計行数の合計: 4
部署未記入: 1
```
