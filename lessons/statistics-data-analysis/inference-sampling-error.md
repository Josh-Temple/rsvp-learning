# 標本分布・標準誤差・標本サイズ

Status: COMPLETE v0.1
Created: 2026-10-31

## 学習目標

個々の値の分布と標本平均の分布を区別できる。標準偏差と標準誤差の違いを説明し、標本数を増やしたときに小さくなる不確実性と、残る偏りを分けられる。
