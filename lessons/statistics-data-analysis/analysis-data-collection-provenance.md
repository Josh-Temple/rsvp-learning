# データ収集・出所・測定誤差

Status: COMPLETE v0.1
Created: 2026-10-31

## 学習目標

調査、業務記録、公的統計の出所と収集目的を確認できる。測定誤差と定義変更を区別し、結果を比較する前に必要なメタデータを挙げられる。

## 本文

1. 問い合わせ窓口の「初回応答までの時間」が
2. 短くなったとします。
3. ところが、以前は担当者の返答、
4. 現在は自動受付メールを初回応答として
5. 記録していました。
6. この架空例では、サービスが速くなったかを
7. 考える前に、同じものを
8. 測っているか確かめる必要があります。
9. 出所を確認するとは、誰が、何のために、
10. どの方法で記録を作り、
11. どんな加工をして手元へ届いたかをたどることです。
12. ファイルの保管場所だけを知っていても、
13. 値の意味までは分かりません。
14. アンケートなら、質問文と回答方法が
15. 測定内容の一部です。
16. 「案内の正確さと速さに満足しましたか」と一度に
17. 尋ねると、どちらへの評価か分かりません。
18. 良い回答を促す表現や、
19. 回答者が理解しにくい言葉も影響し得ます。
20. 何を答えてほしいかを一つずつ示し、
21. 本番前に質問の理解を確かめます。
22. 業務ログは、処理や管理のための記録です。
23. 自動取得でも、利用者が感じた待ち時間を
24. そのまま表すとは限りません。
25. 問い合わせ送信後にしか時計を
26. 動かさない仕組みなら、
27. 送信前に説明を探した時間は含まれません。
28. 記録が正しくても、
29. 知りたい体験の一部しか測っていない場合が
30. あります。
31. 公的統計も、表題だけで利用を決めません。
32. 対象、地域、調査時期、単位、速報か確定値か、
33. 改訂の有無などを確認します。
34. 今回の目的に合わなければ、
35. 信頼できる作成機関の値でも、
36. そのまま比較には使えません。
37. 測定誤差は、測ろうとした量と、
38. 記録した値とのずれです。
39. 機器のずれ、質問の誤解、
40. 記憶に基づく回答などが原因になります。
41. ずれが偶然に変動する場合と、
42. ある方向へ偏る場合を区別します。
43. 件数を増やすだけでは、
44. 全員に共通する時計のずれや、
45. 誘導的な質問による偏りは直せません。
46. 一方、冒頭の応答時間は、
47. 単なる入力誤りではなく定義が変わった例です。
48. 過去の値を一律に訂正すれば済むとは限りません。
49. 人の返信日時が新旧両方に残っていれば再集計で
50. きますが、残っていなければ、
51. 同じ尺度での過去比較はできないと説明します。
52. 記録の発生時刻と、
53. データへ反映された時刻も分けます。
54. 今日取り出した表でも、
55. 数日前までの情報しか入っていないことがあります。
56. 「取得した日」と「何日時点の現象を表すか」は
57. 同じではありません。
58. メタデータは、データの意味や作られ方を
59. 説明する情報です。
60. この例なら、初回応答の定義、対象経路、
61. 時間の単位、夜間の扱い、自動返信の扱い、
62. 更新頻度、変更日などが該当します。
63. 分析者が毎回推測して埋める情報ではありません。
64. 記録が足りない場合は、作成担当者に確かめ、
65. 確認できたことと不明なことを分けて残します。
66. 収集後の加工や、外部からの提供条件も記録します。
67. ただし、出所の確認を理由に、
68. 分析に不要な個人情報まで複製する必要は
69. ありません。
70. 自動メールも含めた応答時間は、
71. 「受信したことを知らせる速さ」を
72. 調べるなら有用です。
73. 同じ指標が常に悪いわけではなく、
74. 目的と意味が合うかが問題です。
75. 次の分析者がその違いを判断できる説明まで
76. 含めて、データを引き継ぎます。

## 注意

具体例は学習用の架空例です。実務では対象・定義・入力データの版を確認してください。
