# 準実験・差の差・回帰不連続

Status: COMPLETE v0.1
Created: 2026-10-31

## 学習目標

差の差の算例と平行トレンドの意味を説明できる。回帰不連続で利用する境界と条件を挙げ、二つの方法がどの対象の効果を問うかを区別できる。
