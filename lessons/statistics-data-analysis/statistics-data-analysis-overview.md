# データ分析と統計の入口

Status: SEED / 概要のみ

## 目的

この章は「データ分析・統計」の入口です。
現時点では網羅的な教材ではありません。
後続章を作るための骨格として置きます。

## 最初に押さえること

- データ分析では、数字を出すだけでなく意味を考えます
- 平均は全体の中心を表す代表値の一つです
- 中央値は、外れ値の影響を受けにくい代表値です
- 分散や標準偏差は、データのばらつきを表します
- 母集団は知りたい対象全体、標本は実際に観測する一部です
- 標本には、選び方による偏りが入ることがあります
- 信頼区間は、推定の不確実性を幅として表します
- 仮説検定は、観測結果が偶然だけで説明できるかを検討します
- 相関があっても、因果関係があるとは限りません
- 回帰は、変数同士の関係をモデル化する代表的な方法です
- 分析では、事前に問いと比較条件を明確にします
- まずは、数字の差とその不確実性を分けて説明できることを目標にします

## 次に深掘りする項目

- 平均と中央値
- 分散と標準偏差
- 母集団と標本
- 信頼区間
- 仮説検定
- 相関と因果
- 回帰
