# KPI・分母・測定単位

Status: COMPLETE v0.1
Created: 2026-10-31

## 学習目標

指標の目的・分子・分母・測定単位・期間を定義できる。件数と割合、問い合わせ回数と人数を区別し、定義の変更によって比較できなくなる例を説明できる。

## 本文

1. 問い合わせ窓口で「再問い合わせが減った」と報告されました。
2. 回数が減ったのか、再び連絡した人の割合が減ったのかによって、意味は変わります。
3. KPIは、目的に向けた状況を継続して確かめる主要な指標です。
4. 指標名だけでは測り方は決まらないため、何を一つと数えるかまで定義します。
5. 以下の件数はすべて学習用の架空値です。
6. ある期間の問い合わせ百件のうち、三十件が同じ問題についての二回目以降の連絡だったとします。
7. 問い合わせ全体に占める再問い合わせの割合は、三十を百で割って百を掛け、三十パーセントです。
8. 割合では、分子に数えた対象が分母にも含まれる必要があります。
9. 一方、連絡した利用者が六十人で、そのうち再び連絡した人が二十人なら、利用者に占める再連絡者は約三十三パーセントです。
10. 一人が三回以上連絡すれば、回数と人数は一致しません。
11. この二つの割合は、同じ数字を別の方法で計算したものではなく、別の問いへの答えです。
12. 式で補えば「再問い合わせの割合＝二回目以降の問い合わせ件数÷全問い合わせ件数×百」です。
13. これは回数を単位とする指標です。
14. 分子を三十件のまま、分母だけ六十人へ変えると、一人当たり零点五件という別の量になります。
15. 「利用者の五十パーセントが再問い合わせした」とは読めません。
16. 「同じ問題」の判定には、問い合わせ番号を引き継ぐのか、内容を人が分類するのかという規則が必要です。
17. 電話とメールを別々に数えるのかも決めます。
18. 氏名が同じだから同一人物と断定するなど、不確かな照合で人数を作らないようにします。
19. 期間も測定の一部です。
20. 月末に初めて問い合わせた人は、翌月に再連絡するかもしれません。
21. 当月中の再連絡だけを数えると、月初の利用者と追跡時間が違います。
22. 「初回から七日以内」を見るなら、七日分を観測できた利用者を対象にし、まだ七日たっていない人を再連絡なしと確定しません。
23. 七日はこの例の編集上の設定で、一般の推奨値ではありません。
24. 分母が零なら割合は計算できません。
25. 対象者なしと、対象者はいたが再連絡が零だった場合は区別します。
26. また、確認できなかった連絡を「再連絡なし」へ置き換えると、数字だけは良くなり得ます。
27. 計算対象、除外理由、不明件数を結果と一緒に残します。
28. 次の期間に再問い合わせが二十件へ減っても、全問い合わせが五十件なら割合は四十パーセントです。
29. 回数は減り、割合は上がっています。
30. 窓口の総負担と、一度で問題が解決したかは違う問いなので、どちらか片方を誤りと決めず、目的に合わせて読み分けます。
31. 再問い合わせの少なさも、問題解決を直接観測したものではありません。
32. 連絡しにくくなって諦めた人が増えた場合にも下がり得ます。
33. 一次対応で解決できたかを知りたいなら、利用者への確認や未解決の記録も必要です。
34. 主指標に加え、見落とすと困る負担や不利益を確認する補助指標を置きます。
35. 測定の定義には、目的、数える単位、分子、分母、期間、除外と不明の扱い、出所を記します。
36. 途中で電話だけから全経路へ変えたなら、同じ「再問い合わせ率」という名前でも連続比較はできません。
37. 旧定義で再計算するか、変更点を示して系列を分けます。
38. 良い指標は数字を一つに絞ることより、その数字で何を判断できるかが明確な指標です。

## 注意

数値は学習用の架空例です。定義や比較条件は実際の業務に合わせて確認します。
