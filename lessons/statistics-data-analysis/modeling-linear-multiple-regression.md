# 単回帰・重回帰と係数解釈

Status: COMPLETE v0.1
Created: 2026-10-31

## 学習目標

回帰式の目的変数、説明変数、切片、係数を単位とともに説明できる。重回帰の係数を他の変数を一定としたモデル内の関係として読み、因果効果との違いを述べられる。

## 本文

1. 配送時間を距離から見積もるとします。
2. 予測したい配送時間が目的変数、
3. 入力する距離が説明変数です。
4. 説明変数が一つの回帰を単回帰、
5. 複数を使う回帰を重回帰と呼びます。
6. 以下は式の読み方を学ぶ架空例で、
7. 実データに当てはめた推定結果ではありません。
8. 平均的な配送時間を「二十分に、
9. 一キロメートルにつき二分を加える」と表し
10. てみます。
11. 補助の式は `予測時間＝20＋2×距離` です。
12. 距離をキロメートルで入れると、時間は分で出ます。
13. 三キロなら二十に六を足して二十六分です。
14. 距離の係数二は、一キロメートルの違いに対して、
15. 予測時間が二分違うというモデル内の関係です。
16. 距離をメートルへ変えれば係数の数字も変わります。
17. 係数の大小を、単位を確認せず比べないようにし
18. ます。
19. 切片の二十は、説明変数がすべて零のと
20. きの予測値です。
21. 距離零の配送が現実に存在せず、
22. 観測範囲からも離れていれば、
23. 切片だけに強い意味を持たせません。
24. 個々の配送には、モデルに表れていない事情に
25. よるずれも残ります。
26. 混雑時間帯かどうかも入力します。
27. 通常時間帯を零、混雑時間帯を一とした変数を
28. 作り、`予測時間＝20＋2×距離＋5×混雑` 
29. と置きます。
30. 三キロなら、通常は二十六分、
31. 混雑時は三十一分です。
32. 距離の係数は、混雑区分が同じという条件で
33. の一キロ当たりの違いです。
34. 混雑の係数五は、距離が同じなら二つの区分で
35. 五分違うという意味です。
36. 「他の条件を一定」とは、
37. このモデルに入れた変数についての話で、
38. 天候や道路事情まで同じになったという意味では
39. ありません。
40. この式では、混雑による違いが距離に
41. よらず五分だと置いています。
42. 長距離ほど混雑の影響が大きいなら、
43. この形は不十分かもしれません。
44. そのような条件による違いは、
45. 交互作用を扱う診断の章で考えます。
46. 最小二乗法は、観測値とモデル値のずれを二乗し、
47. その合計が最も小さくなるよう係数を選ぶ方法です。
48. 大きなずれは二乗で強く効くため、
49. 極端な観測値の影響も確認します。
50. 線形という名称は、
51. 係数が足し算で入る形を指します。
52. 距離の二乗を説明変数に加えた曲線でも、
53. 係数について線形なモデルは作れます。
54. 一方、説明変数同士がほぼ同じ情報なら、
55. 個々の係数を安定して分けにくくなることが
56. あります。
57. 重回帰で調整したからといって、
58. 混雑を変えた場合の因果効果が分かるとは
59. 限りません。
60. 係数を読む際は、変数の単位、固定した条件、
61. 使った範囲、残した要因を示します。
62. 因果を主張するなら、
63. モデルの適合とは別に比較の妥当性を説明します。
