# データ品質・欠損・非回答

Status: COMPLETE v0.1
Created: 2026-10-31

## 学習目標

欠損、非回答、対象漏れ、入力誤りを区別できる。回答者だけの割合が全対象者の割合とは限らない理由を説明し、安易な零置換や完全な行だけの分析を評価できる。

## 本文

1. 架空の研修で、対象者百人のうち八十人が回答し、六十人が「役立った」と答えたとします。
2. 回答者の中では七十五パーセントです。
3. しかし、百人全体の七十五パーセントが役立ったと答えたわけではありません。
4. 残る二十人の答えは分からないからです。
5. 以下の数字は学習用の架空値です。
6. データ品質は、今回の用途に使えるかという目的との関係で評価します。
7. すべての値がある完全性、同じ対象の不要な重複がないこと、形式が定義に合うこと、現実と一致する正確性などは別の観点です。
8. 日付の形式が正しくても、別人の日付なら正確ではありません。
9. 値が記録されていない状態を欠損と呼びます。
10. 調査への回答自体がない単位非回答と、回答はあるが一部の設問が空いている項目非回答を分けます。
11. 名簿に最初から載っていない人は対象漏れの問題であり、表の空欄を探すだけでは見つかりません。
12. また、設問に該当しないための空欄、答えたくないための空欄、記録の送信失敗を区別します。
13. 「研修へ参加していないので教材の評価は該当しない」と「参加したが無回答」は同じ意味ではありません。
14. 原因を確認できなければ、不明のまま残します。
15. 満足度が一から五の設問で、空欄を零へ置き換えると、実際には選べない低評価を加えることになります。
16. 逆に、空欄の行をすべて削除しても、残った人だけの結果になります。
17. 入力がそろったことは、対象を適切に代表する証拠ではありません。
18. 欠損の仕組みには標準的な区分があります。
19. 欠ける確率が観測済み・未観測の値に依存しないものをMCAR、完全に無作為な欠損と呼びます。
20. 観測済みの情報で条件付けると、欠けた値自体には依存しないものがMAR、無作為な欠損です。
21. MCARと違い、観測済みの情報によって欠けやすさが異なっていても成り立ちます。
22. 「無作為」という語でも、何も考えず無視してよいという意味ではありません。
23. その条件をそろえても、未観測の値に欠けやすさが依存するものがMNAR、無作為でない欠損です。
24. 研修への不満が強い人ほど回答しないなら、その可能性があります。
25. ただし、回答がない人の満足度は見えないため、観測データだけでMARかMNARかを確定できるとは限りません。
26. これらは分析で置く仮定としても点検します。
27. 冒頭の例で、無回答の二十人が全員「役立たなかった」なら、全対象者の肯定割合は六十パーセントです。
28. 全員「役立った」なら八十パーセントです。
29. 他の誤りがないという条件でも、回答者の七十五パーセントだけから全体の値を決められません。
30. この幅は算術上の範囲であり、信頼区間ではありません。
31. 実務では、回答の有無を、分かっている所属や参加方法などと比べます。
32. 無回答の理由の聞き取りや追加回収も候補です。
33. 重み付けや欠損値の補完を行う方法もありますが、補った値は新しく観測した事実ではなく、仮定を使った推定です。
34. 欠損を完全に直せないときも、回答数と無回答数、除外した対象、処理方法と仮定、結論が変わり得る範囲を示せます。
35. 欠損が少ないかどうかだけで、偏りが小さいと決めないことが判断の基礎になります。

## 注意

具体的な数値や組織は、特に断りのない限り学習用の例です。実務では対象と条件を確認してください。
