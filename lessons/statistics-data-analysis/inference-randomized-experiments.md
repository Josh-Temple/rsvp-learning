# 無作為化実験・比較群・交絡

Status: COMPLETE v0.1
Created: 2026-10-31

## 学習目標

無作為抽出と無作為割当を区別できる。同時期の比較群が必要な理由を説明し、干渉や脱落によって比較が崩れる場合を指摘できる。

## 本文

1. 予約忘れを減らすため、新しい案内文を試すとします。
2. 導入前より欠席が減っても、季節や予約者の構成が変わっただけかもしれません。
3. そこで、同じ時期の対象者を、従来の案内を受ける比較群と、新しい案内を受ける介入群に分けます。
4. 以下は架空のサービス実験です。
5. 比較群は、新しい案内がなければ何が起きたかを考える手掛かりになります。
6. ただし、希望者だけに新しい案内を送ると、もともとの意欲の違いも結果に混ざります。
7. 案内の種類と欠席の両方に関係する要因が、比較を歪める交絡の問題です。
8. 無作為割当は、対象者がどちらの条件を受けるかを確率的な手続きで決めます。
9. 適切に行えば、測定した要因だけでなく、測定していない要因も、割当の繰り返しでは平均的に釣り合うことが期待できます。
10. 一度の小規模実験で、すべての属性が完全に同じになる保証ではありません。
11. 母集団から調べる人を選ぶ無作為抽出とは役割が違います。
12. 実験参加者への割当が無作為でも、参加者自体が限られた利用者なら、結果を全住民へ一般化できるとは限りません。
13. 予約を一人が何度も行うサービスでは、予約ごとか利用者ごとか、割当の単位を定めます。
14. 同じ人が両方の案内を受けると、先に見た案内の影響が残るかもしれません。
15. 観測件数を増やしても、独立した対象者が増えたとは限らないため、分析も設計に合わせます。
16. 新しい案内を最後まで読んだ人だけを介入群に残すと、読みやすさに加え、本人の関心も選別条件になります。
17. 割当の利点を保つ基本は、実際に読んだかによらず、最初に割り当てた群で比較することです。
18. これは割当の効果を問う分析であり、必ず読んだ場合の効果とは区別します。
19. 各群百人で、欠席者が従来群二十人、新案内群十五人なら、観測した欠席率の差は五パーセントポイントです。
20. しかし、結果が不明な人を分母から黙って外すと比較は変わります。
21. 全員の結果を追う努力と、不明者数・理由の記録が必要です。
22. 元の群に戻して数えるだけでは、結果の欠損による偏りは解決しません。
23. 案内を受けた人が家族に内容を共有すると、比較群も影響を受けるかもしれません。
24. このように、一人への介入が別の人の結果に及ぶことを干渉と呼びます。
25. 必要なら家族や拠点単位の割当を検討し、その単位に合う解析を計画します。
26. 実験前には、対象、割当方法、測る期間、脱落や混在の扱いを決めます。
27. 利用者への負担や不利益も点検します。
28. 無作為化は比較の根拠を強めますが、運用や測定の問題を無条件に消す仕組みではありません。

## 注意

具体的な数値や組織は、特に断りのない限り学習用の例です。実務では対象と条件を確認してください。
