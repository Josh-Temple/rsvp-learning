# 相関・回帰・因果関係

Status: COMPLETE v0.1
Created: 2026-09-27

## 学習目標

暑さ、飲料の売上、熱中症搬送の例で、相関・回帰・因果関係の違いを学びます。

## 本文

1. 暑い日に、冷たい飲み物の売上と熱中症の搬送が増えたとします。
2. 二つの値が一緒に動くことを、相関として捉えられます。
3. 売上が搬送を増やしたとはこの観察だけでは言えません。
4. 気温が、両方に影響する第三の要因かもしれません。
5. 搬送が多いから飲み物を買うという逆方向も考えられます。
6. ピアソンの相関係数は、直線的な関係の向きと強さを要約します。
7. 係数がゼロに近くても、曲線的な関係を見落とすことがあります。
8. まず散布図で、外れ値や関係の形を確認します。
9. 回帰は、説明変数から結果の変化を表すモデルです。
10. 売上と搬送の関係を、気温も加えて比べる方法があります。
11. ただし、気温を入れれば因果関係が証明されるわけではありません。
12. 記録していない条件や、測定方法の問題が残るからです。
13. 回帰係数は、モデルと含めた変数の条件で意味が変わります。
14. 予測に役立つ変数でも、結果を変える原因とは限りません。
15. 原因を確かめるには、比較する集団の作り方が重要です。
16. 無作為に介入を割り当てる実験は、因果を調べる強い方法です。
17. しかし、実験できない場合もあります。
18. 観察データを使うときは、選択の偏りや交絡の可能性を検討します。
19. いつ測った値かと、先に起きた出来事も確認します。
20. 結論は、関連を見たのか、原因を検証したのかを分けます。

## 注意

この章は基礎理解用です。
実務で判断するときは、対象システムの仕様、組織ルール、データの前提を別途確認します。
