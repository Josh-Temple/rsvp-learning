# 相関・回帰・因果関係

Status: COMPLETE v0.1
Created: 2026-09-27

## 学習目標

暑さ、飲料の売上、熱中症搬送の例で、相関・回帰・因果関係の違いを学びます。

## 本文

1. 暑い日に、冷たい飲み物の売上と熱中症の搬送が増えたとします。
2. 二つの値が一緒に動くことを、相関として捉えられます。
3. 売上が搬送を増やしたとはこの観察だけでは言えません。
4. 気温が、両方に影響する第三の要因かもしれません。
5. 搬送が多いから飲み物を買うという逆方向も考えられます。
6. ピアソンの相関係数は、直線的な関係の向きと強さを要約します。
7. 係数がゼロに近くても、曲線的な関係を見落とすことがあります。
8. まず散布図で、外れ値や関係の形を確認します。
9. 回帰は、説明変数から結果の変化を表すモデルです。
10. 売上と搬送の関係を、気温も加えて比べる方法があります。
11. ただし、気温を入れれば因果関係が証明されるわけではありません。
12. 記録していない条件や、測定方法の問題が残るからです。
13. 回帰係数は、モデルと含めた変数の条件で意味が変わります。
14. 予測に役立つ変数でも、結果を変える原因とは限りません。
15. 原因を確かめるには、比較する集団の作り方が重要です。
16. 無作為に介入を割り当てる実験は、因果を調べる強い方法です。
17. しかし、実験できない場合もあります。
18. 観察データを使うときは、選択の偏りや交絡の可能性を検討します。
19. いつ測った値かと、先に起きた出来事も確認します。
20. 結論は、関連を見たのか、原因を検証したのかを分けます。
21. 広告を増やした週に売上も増えました。
22. 同じ週に休日が重なったとします。
23. 広告以外の要因と比較条件を調べます。
24. 一緒に増えれば広告の効果ですか。
25. 観察だけでは原因を確定できません。

26. 相関の強さだけで因果を決めません。
27. 時系列の順序も確認します。
28. 第三の要因を検討します。
29. 選択の偏りもあり得ます。
30. 回帰は条件付き関係を表せます。
31. モデル前提を確認します。
32. 予測精度と因果解釈を分けます。
33. 因果には追加の設計が必要です。
34. 架空の三週間を使って、数値も確かめます。
35. 広告費が一、二、三万円の週に、
36. それぞれ二十、三十、四十件の
37. 注文があったとします。
38. 観測した単位は一週間です。
39. 三つの点は完全な右上がりの直線に並びます。
40. この三点のピアソン相関係数はプラス一。
41. 直線的な関連が完全であることを表します。
42. この三点に直線回帰を当てはめると、
43. 予測注文件数は十に広告費の
44. 万円単位の値を十倍して足した値です。
45. 広告費一万円では二十件、
46. 二万円では三十件となり、
47. この三点には誤差なく一致します。
48. 広告費の係数十は、
49. このデータとモデルでは一万円の違いに
50. 十件の予測差が対応するという意味です。
51. 広告費を一万円増やせば、
52. 注文が必ず十件増える証拠ではありません。
53. 例えば三週間で季節的な需要が増え、
54. 広告費も計画どおり増えたのかもしれません。
55. 需要の増加が先に見込まれたから
56. 広告予算を増やした可能性もあります。
57. 三点だけでは、こうした説明を分けにくく、
58. 他の期間でも関係が続くかも分かりません。
59. 観測していない四万円に対して
60. 五十件を予測するのは外挿です。
61. 直線が範囲外でも成り立つとは限りません。
62. 施策の効果を知りたいなら、
63. 同じ時期に比較できる集団を設計するなど、
64. 別の因果推論の根拠を調べます。
65. 相関係数、回帰による予測、
66. 介入による効果を別々に説明します。

## 注意

この章は基礎理解用です。
実務で判断するときは、対象システムの仕様、組織ルール、データの前提を別途確認します。
