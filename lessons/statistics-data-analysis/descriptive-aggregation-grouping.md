# 集計・層別比較・重み付き平均

Status: COMPLETE v0.1
Created: 2026-10-31

## 学習目標

集計軸と数える単位を説明できる。群の平均から全体平均を求め、単純平均と重み付き平均で答える問いが変わる理由を示せる。

## 本文

1. 架空の二店舗で、来店者の待ち時間を調べました。
2. 店舗Aは十人で平均二分、
3. 店舗Bは九十人で平均十分です。
4. 二分と十分を足して二で割ると六分ですが、
5. 百人全体の平均待ち時間は六分にはなりません。
6. 以下はすべて架空の計算例です。
7. 集計は、目的に合わせてデータをまとめる操作です。
8. 店舗ごと、日ごと、
9. 商品ごとなどの区分を集計の軸と呼びます。
10. 同じ記録でも、軸と数える単位が変われば、
11. 結果の意味は変わります。
12. Aの待ち時間の合計は、
13. 二分に十人を掛けた二十分です。
14. Bは十分に九十人を掛けた九百分です。
15. 合計九百二十分を百人で割ると、
16. 全来店者の平均は九点二分になります。
17. 大半の来店者がBを利用しているので、
18. 全体平均もBの値に近づきます。
19. これが人数で重み付けした平均です。
20. 式では「各群の平均×各群の人数」を合計し、
21. 全人数で割ります。
22. 一般の重み付き平均も、値に重みを掛けて足し、
23. 重みの合計で割ります。
24. 何を重みとしたかが、平均の意味を決めます。
25. 六分という単純平均も、
26. 計算自体が誤りなのではありません。
27. 「各店舗を同じ重さで見た、
28. 店舗別平均の平均」への答えです。
29. 来店者一人を同じ重さで扱う九点二分とは別です。
30. 店舗運営を比べたいのか、
31. 利用者全体の待ちを知りたいのかを先に決めます。
32. 同じ百人のうち、Aで八人、
33. Bで四十五人が待ち時間に満足したとします。
34. Aは八十パーセント、Bは五十パーセントです。
35. 全体は肯定した五十三人を百人で割り、
36. 五十三パーセントです。
37. 八十と五十の平均の六十五パーセントを、
38. 全来店者の割合として使うと誤ります。
39. 集計済みの割合しかなく、分母が分からなければ、
40. 全体の割合を正しく再構成できない場合があります。
41. 群ごとの平均だけを保管して件数を失った場合も
42. 同様です。
43. 集計結果には、使った件数や合計も添えると、
44. まとめ直すときに確認できます。
45. 層別比較は、条件で分けた群ごとに結果を
46. 比べることです。
47. 店舗ごとの待ち時間に差があれば、
48. 曜日や受付内容などで分けると、
49. 差がどこにあるかを調べられます。
50. ただし、分け方を細かくしすぎると、
51. 各群の件数が少なくなり、
52. 一件の違いで大きく動きます。
53. たとえば、一店舗に難しい手続が集中していれば、
54. 店舗平均の差は担当者の能力だけを表していません。
55. 層別は比較条件の違いに気付く手段ですが、
56. 群を分けただけで因果関係が確定するわけでは
57. ありません。
58. 構成の違いで全体の比較が逆転する例は、
59. 別の章で扱います。
60. また、すでに人数で重み付けされた集計に、
61. もう一度人数を掛けるなど、
62. 重みの二重適用にも注意します。
63. 単なる件数の重みと、
64. 調査で対象集団へ広げるための抽出の重みは目的が
65. 違うため、同じものとして扱いません。
66. 結果をまとめるときは、
67. 「誰または何を等しく数えるか」を一文で説明し
68. ます。
69. 全体の平均と群別の結果を併記すれば、
70. 全体の経験と、どこを改善するかと
71. いう二つの判断を分けて考えられます。

## 注意

すべての具体例は学習用の架空例です。対象・分母・出典・観測条件は実際の判断時に再確認してください。
