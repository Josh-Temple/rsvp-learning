## 最初に押さえること

- ネットワークは、複数の機器やサービスを接続します
- IPアドレスは、ネットワーク上の機器を識別します
- TCPは、信頼性のある通信を提供する代表的な仕組みです
- DNSは、ドメイン名をIPアドレスへ対応づけます
- Portは、一台の機器内で通信先のサービスを区別します
- HTTPはWeb通信、TLSは通信の暗号化に使われます
- OSは、アプリとハードウェアの間で資源を管理します
- Processは、実行中のプログラムです
- Memoryは、処理中のデータを保持する重要な資源です
- Filesystemは、ファイルとディレクトリを管理します
- Linuxの基本操作は、クラウドやサーバー理解に役立ちます
- まずは、ブラウザからサーバーまで通信が届く流れを説明できることを目標にします
