# 攻撃者・動機・初期アクセス

Status: COMPLETE v0.1
Created: 2026-10-08

## 学習目標

攻撃者の属性を推測することより、何を狙い、どの入口を使い得るかを整理し、初期アクセスの防御と検知へつなげられるようにします。

## 本文

1. 攻撃者をラベルだけで見ません。
2. 目的から考えます。
3. 金銭目的の場合があります。
4. 情報窃取が目的の場合もあります。
5. 妨害が目的の場合もあります。
6. 影響力の獲得を狙う場合もあります。
7. 内部者が関係する場合もあります。
8. 能力も一様ではありません。
9. 使える時間も異なります。
10. 使える資源も異なります。
11. 対象への知識も異なります。
12. 帰属判断は慎重に扱います。
13. 技術だけで断定しません。
14. 防御では行動を見ます。
15. 侵入前に偵察する場合があります。
16. 公開情報を集める場合があります。
17. 対象の技術を調べる場合があります。
18. 連絡先を調べる場合もあります。
19. 攻撃用資源を準備する場合があります。
20. 初期アクセスは入口です。
21. 侵害全体と同じ意味ではありません。
22. フィッシングが入口になります。
23. 公開システムの弱点も入口です。
24. 外部リモートサービスも入口です。
25. 有効なアカウントも悪用されます。
26. 信頼関係も入口になり得ます。
27. 供給網も入口になり得ます。
28. 複数経路を想定します。
29. 一つを閉じれば終わりではありません。
30. 公開資産を把握します。
31. 不要な公開口を減らします。
32. 脆弱性を継続管理します。
33. 認証を強化します。
34. メール対策も重ねます。
35. 委託先との接続も確認します。
36. 初期アクセスの兆候を見ます。
37. 異常なログインを確認します。
38. 新しい端末からの利用も見ます。
39. 不審なメール報告も使います。
40. 公開サービスの異常も見ます。
41. 侵入成功を前提にも備えます。
42. 最小権限で影響を抑えます。
43. 分離で横展開を難しくします。
44. ログで後続行動を追います。
45. 攻撃者の目的は途中で変わる場合があります。
46. アクセスが売買される場合もあります。
47. 別の攻撃者へ引き継がれる場合もあります。
48. 一つの攻撃者像に固定しません。
49. 行動と対象資産を結びます。
50. 脅威シナリオとして管理します。

## 注意

この章では攻撃者の目的と初期アクセスを防御判断のために扱います。実在組織への侵入方法や、攻撃の再現手順は扱いません。
