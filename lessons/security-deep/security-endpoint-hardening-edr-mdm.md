# Endpoint hardening・EDR・MDM

Status: COMPLETE v0.1
Created: 2026-10-08

## 学習目標

Endpoint製品の導入有無だけでなく、Coverage、Configuration、Telemetry、Isolation、Mobile lifecycleまで実効性を評価できるようにします。

## 本文

1. Endpointは利用者に近い資産です。
2. 攻撃の入口になる場合があります。
3. 認証情報も存在します。
4. 業務Dataも存在します。
5. 安全な設定を適用します。
6. 不要な機能を減らします。
7. Local adminを減らします。
8. Patchを適用します。
9. OSだけではありません。
10. Applicationも更新します。
11. Browserも重要です。
12. DriverやFirmwareも確認します。
13. Disk encryptionを使います。
14. 紛失時のData保護に役立ちます。
15. Screen lockも設定します。
16. アプリの実行制御も使えます。
17. 許可Softwareを管理します。
18. Macro policyも管理対象です。
19. Removable mediaも考えます。
20. Anti-malwareを維持します。
21. EDRはEndpointを観測します。
22. Process行動を収集できます。
23. File eventも見られます。
24. Network eventも使えます。
25. DetectionとResponseを支えます。
26. 隔離機能を持つ場合があります。
27. EDRだけで完全防御ではありません。
28. Agent coverageを確認します。
29. 停止状態を監視します。
30. Policy差分も確認します。
31. Telemetry送信を確認します。
32. MDMはMobile管理に使います。
33. 設定を配布できます。
34. Complianceを確認できます。
35. 遠隔LockやWipeも使えます。
36. 組織所有の端末もあります。
37. BYODもあります。
38. 管理範囲を分けます。
39. Privacyを考慮します。
40. 仕事用の領域を使う場合があります。
41. App dataを分離します。
42. 紛失手順を整備します。
43. 退職時のData削除も設計します。
44. 廃棄時も消去します。
45. Inventoryと連動します。
46. 未管理端末を検出します。
47. 重要なアクセスを管理端末に限定できます。
48. 端末のログを事故対応に利用します。
49. Lifecycle全体で端末を守ります。

## 注意

EndpointとMobileの管理方法はOSや所有形態で変わります。BYODの場合はPrivacyと組織の管理権限の境界も明確にします。
