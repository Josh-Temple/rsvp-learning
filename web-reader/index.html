RSVP Web Reader

Android Chromeのbookmarklet実行可否を、短いコードから順に切り分けます。

1. まず実行テスト

最初に約500文字の極小コードで、Android ChromeがJavaScriptブックマークを実行できているか確認します。

成功すると、閲覧中ページの最下部に「RSVP TEST OK」が5秒だけ表示されます。

2. テストが成功したら軽量RSVP

初版は約1万文字あったため、Android向けに約6千文字まで削った版です。

選択中の文章があれば選択範囲を優先します。未選択なら article / main / body から本文を取得します。

登録と実行

  1. 上のボタンでコードをコピーします。
  2. Chromeで適当なページをブックマークします。
  3. ブックマークを編集し、名前を RSVP TEST または RSVP Reader にします。
  4. URL欄を全部消して、コピーした javascript: から始まる文字列を貼り付けて保存します。
  5. Wikipediaなど通常のWebページを開きます。
  6. ブックマーク一覧から開かず、そのページを表示したままアドレスバーへブックマーク名を入力します。
  7. ★印の付いたブックマーク候補をタップします。

テスト版では、本文を外部サーバーへ送信しません。
