# 情報セキュリティ本編レビュー — 2026-09-28

基点: main `360a2b59724d81c31789ab2aed4f37dd2c11fae6`

## 目的

入口のSEEDだけだった情報セキュリティを、広く浅い体系理解に使える本編へ拡張します。

試験対策そのものを目的にはしませんが、IPAの情報セキュリティマネジメント試験シラバスを範囲確認の参考にしつつ、NIST・OWASP等の一次資料で主要概念を確認しました。

## 追加した7章

1. 機密性・完全性・可用性とリスク
2. 暗号・ハッシュ・デジタル署名
3. 認証・認可・アクセス制御
4. ネットワークと端末の防御
5. 脆弱性と安全なソフトウェア開発
6. インシデント対応と復旧
7. セキュリティガバナンスと供給網

既存の `information-security-overview` は入口SEEDとして残し、本編7章を `COMPLETE v0.1` として追加します。

## 範囲の考え方

このコースだけで個別のセキュリティ設計を確定することは目的にしません。

到達目標は、少なくとも次を区別して説明できることです。

- 機密性・完全性・可用性
- 脅威・脆弱性・影響・リスク
- 暗号化・ハッシュ・デジタル署名
- 認証・認可・最小権限
- 境界防御と多層防御
- 脆弱性修正と安全な開発
- 検知・対応・復旧
- 技術対策とガバナンス
- 自組織と供給網のリスク

## 主な一次資料

- NIST Cybersecurity Framework 2.0
- NIST SP 800-63B-4
- NIST SP 800-207
- NIST SP 800-218
- NIST SP 800-61 Rev. 3
- NIST SP 1305
- NISTの暗号関連標準
- OWASP Top 10:2025
- IPA 情報セキュリティマネジメント試験シラバス案内

暗号アルゴリズムや認証方式など現在性が重要な具体仕様は、教材内で固定的な推奨値を増やさず、利用時点の標準を確認する射程に留めています。
