# Listen HTML 生成仕様

Status: CURRENT
Updated: 2026-09-28

## 目的

ニュース、調査結果、レポート、資料要約、作業結果などを、Android Chromeで画面を見続けずに連続して聞けるListen HTMLとして保存するための実装仕様です。

上位ルールは Project Source の「Listen / Learn HTML 生成ルール v0.1」です。ユーザーの個別指示がある場合はそちらを優先します。

## Learnとの違い

Listenは体系的な教材ではなく、その時点で把握したい情報を耳で追うためのモードです。

基本の流れは次を優先します。

1. 今回扱う内容
2. 何が起きたか・何が分かったか
3. 背景
4. 意味や影響
5. 条件・限界・未確認点
6. 最後に残す要点

内容に合わない場合は機械的に固定しません。

## 対象

- ニュース
- Web調査
- Deep Research等の調査結果
- GitHubやプロジェクトのレビュー
- 研究結果
- 長い資料の要約
- 日常的に聞きたいメモやレポート

## 時点管理

Listenは時間依存の情報を多く含むため、作成日または情報基準日を必ず明確にします。

古いListen HTMLを後から開いても、その時点の情報であることが分かる状態を保ちます。

現在性が重要な事実は、生成時点で必要な確認を行います。

## 文章

- 音声だけで論旨を追える自然な日本語にする
- 一文を過度に長くしない
- テーマが切り替わるときは接続表現を入れる
- 事実と分析・解釈を混同しない
- 調査結果では結論だけでなく重要な根拠・条件・限界を残す
- 表、複雑な箇条書き、脚注番号へ依存しない
- 「上記」「下表」「右図」など画面位置依存の表現を避ける
- ポッドキャスト風の挨拶や架空の会話を足さない
- 本文中に生URLを置かない

## HTML

原則として単一HTMLファイルで完結させます。

- UTF-8
- `<html lang="ja">`
- `main` と `article` を中心に構成
- `h1`〜`h3` と `p` を基本にする
- 本文は初期DOMへ通常テキストとして置く
- 外部フレームワークや外部フォントを必須にしない
- CSSは最小限
- 出典は本文後に置く

## 読み上げ

Learnと同じページ内 Web Speech API を標準経路とします。

- 再生
- 一時停止
- 停止
- 日本語音声選択
- 0.7〜4.0倍速
- 見出し・段落単位の連続読み上げ
- 現在位置のハイライト
- 読み上げ中のScreen Wake Lockによる自動消灯抑止

Chrome標準の「このページを読み上げ」には依存しません。

対応ブラウザでは再生開始時に Screen Wake Lock API の `screen` ロックを要求し、読み上げ中の自動消灯を抑止します。一時停止中もロックを維持し、停止・完了・エラー・ページ離脱時に解除します。タブが再表示された場合は必要に応じて再取得します。

Wake Lockはbest-effortです。未対応またはOS側で拒否された場合でも読み上げ自体は継続します。Android Chromeではバックグラウンド再生を保証しません。

## Listen一覧への登録

完成したListen HTMLは `listen/index.json` に登録します。

最低限の形式:

```json
{
  "id": "2026-09-28-example",
  "title": "表示タイトル",
  "date": "2026-09-28",
  "category": "research",
  "path": "./research/2026-09-28-example.html"
}
```

`category` は原則として次から選びます。

- `news`
- `research`
- `report`
- `note`

必要になった場合だけ追加します。

## ファイル配置

例:

```text
listen/
  index.html
  index.json
  news/
    2026-09-28-ai-news.html
  research/
    2026-09-28-topic.html
  reports/
    2026-09-28-project-review.html
```

日付をファイル名へ含め、時間依存情報であることを識別しやすくします。

## 出典

出典がある場合は本文後へまとめます。

- 生URLを表示テキストにしない
- 資料名・媒体名をリンク文字列にする
- 元資料にない出典を推測で足さない
- 出典を読み上げ対象外にしても、HTML上から削除しない

## 生成後チェック

- 情報基準日または作成日が明確
- 冒頭だけで何を扱うか分かる
- 事実と分析が混ざっていない
- 条件・限界・未確認点を落としていない
- 音声だけで話題転換が分かる
- 表や画面位置へ依存していない
- Web Speech APIプレイヤーがある
- Screen Wake Lock APIをbest-effortで利用し、停止・完了時に解除する
- 速度上限が4.0倍
- `listen/index.json` へ登録されている
- pathが実ファイルと一致する
