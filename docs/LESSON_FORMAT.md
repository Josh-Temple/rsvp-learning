# 教材フォーマット

教材は、アプリ側で日本語を自動分割せず、作成時点でRSVP用の表示単位まで確定したJSONとして保存します。

## 方針

- 1チャンク = 一度に意味を把握しやすい短いまとまり
- 助詞だけを単独チャンクにしない
- 固有名詞、数値、専門用語は不自然に分割しない
- 句読点そのものを表示する必要はない
- 文・段落の区切りや重要語では `duration_multiplier` を大きくする
- 原典の長い文章をそのまま転載せず、学習用に独自の説明文へ再構成する
- 調査教材では `sources` に確認に使った資料を残す

## RSVPチャンクの境界チェック（2026-10-08）

24文字以内でも、専門用語の途中でチャンクが切れていれば意味を理解しにくくなります。

- 隣接するチャンクの末尾・先頭がともに英字なら、専門用語の途中分割が疑われるためエラーとして検出します。
- 助詞で終わる境界は、文節や述語が不自然に切れている可能性があるためレビュー候補にします。すべて誤りとは断定しません。
- 現段階での必須ゲートは `lessons/security-deep/` に限定します。他の教材は既存表現の監査後に対象を広げます。
- 検出ルールは日本語の意味を判定するものではありません。速読時の理解、自然な分割、用語の読ませ方は人が確認します。
- 修正したらMarkdownの番号付き本文とJSONのチャンク連結を同じコミットで同期し、関連テストも実行します。

## 教材statusと完成条件

`lessons/index.json` の全Lessonに `status` を必須で持たせ、対応するMarkdown原稿の `Status:` と同じ値にします。RSVP JSON自体にはstatusを重複させません。status一覧は次の3つです。

| status | 意味 |
|---|---|
| `SEED / 概要のみ` | 概要段階の教材です。初版教材としては未完成です。 |
| `DRAFT v0.1` | 原稿またはレビューに未解決の問題がある教材です。Learn HTMLを生成しません。 |
| `COMPLETE v0.1` | 下記の完成条件を満たし、RSVP版とLearn版の初版に使える教材です。 |

`DRAFT v0.1` から `COMPLETE v0.1` へ進める条件は、次のすべてです。

- 教材タイトル、学習目標、本文が一致し、主要概念と教材の射程が明確である。
- 初学者が説明の順を追え、用語の意味が分かり、重大な説明飛躍や内部矛盾がない。
- 明らかな事実誤認がなく、レビュー記録に残った重大な問題が解決済みである。
- 日本語が実用的で、RSVPの各チャンクでも意味が保たれる。
- Markdown本文の番号付き項目を連結した内容と、RSVP JSON `chunks[].text` の連結が一致する。空チャンクがなく、既存検証を通過し、24文字を超えるチャンクが残っていない。
- Markdownの出典とJSON `sources` が一致する。本文、出典またはmetadataを変更した場合は、MarkdownとJSONを同じ変更で同期し、再検証する。

出典は一律必須ではありません。現在性が重要な仕様、数値、制度・法令・規則、セキュリティ上の推奨、ベンダー固有仕様、標準規格、特定の研究結果、または確認が難しい具体的主張には出典を付けます。一般的で争いの少ない概念説明やリポジトリ内で完結する構造説明は、出典がないことだけで未完成にはしません。必要性を判断できない主張は安全だと推測せず、根拠を確認するまで `DRAFT v0.1` に置きます。

Learn HTMLは `COMPLETE v0.1` の教材だけから生成できます。生成時は完成済みMarkdownを主入力とし、同じ知識範囲の音声向け連続文章へ再構成します。RSVP JSONのチャンクを単純連結してLearn本文にしません。Learn HTMLの初期DOMに本文を置き、カタログの `learn_path` と一致させます。

完成後に重大な誤りや欠落が分かった場合は、修正中の教材を `DRAFT v0.1` に戻し、Markdownとカタログを同時に更新し、`learn_path` と当該Learn HTMLを外します。再レビュー、RSVP JSON同期、validationを終えてから再び `COMPLETE v0.1` にし、Learn HTMLを生成します。

## 表示時間

実際の表示時間は次で決まります。

```
表示時間 = base_duration_ms × duration_multiplier ÷ 再生速度
```

例:

- 通常チャンク: `1.0`
- 短く予測しやすいチャンク: `0.8–0.9`
- 文末・重要概念: `1.2–1.5`
- 特に難しい数値や専門語: 必要に応じてさらに長くする

値は固定規則ではなく、実際の読みやすさを優先して調整します。

## 教材一覧

新しい教材を追加したら `lessons/index.json` に登録します。

```json
{
  "id": "example",
  "title": "教材名",
  "topic": "分野",
  "path": "./lessons/topic/example.json"
}
```

JSONの構造は `schema/lesson.schema.json` を正本とします。
