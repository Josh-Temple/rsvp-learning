# 教材フォーマット

教材は、アプリ側で日本語を自動分割せず、作成時点でRSVP用の表示単位まで確定したJSONとして保存します。

## 方針

- 1 Lesson = Course上の1 Chapterとして扱う
- Chapterは知識体系として意味のあるまとまりを優先し、文字数だけで細分化しない
- 長いChapterでも、RSVPチャンクが適切なら一つのLessonとして保持できる
- ランダム再生を前提に、各Lessonは単独で開始しても主題を理解できる導入を持つ
- Lesson内で略語を初めて使うときは、必要に応じて正式名称または短い定義を先に示す
- 前のLessonを見ないと意味が取れない「これ」「前述の方法」などの参照表現を避ける
- 1チャンク = 一度に意味を把握しやすい短いまとまり
- 助詞だけを単独チャンクにしない
- 固有名詞、数値、専門用語は不自然に分割しない
- 句読点そのものを表示する必要はない
- 文・段落の区切りや重要語では `duration_multiplier` を大きくする
- 原典の長い文章をそのまま転載せず、学習用に独自の説明文へ再構成する
- 調査教材では `sources` に確認に使った資料を残す

## 表示時間

実際の表示時間は次で決まります。

```
表示時間 = base_duration_ms × duration_multiplier ÷ 再生速度
```

例:

- 通常チャンク: `1.0`
- 短く予測しやすいチャンク: `0.8–0.9`
- 文末・重要概念: `1.2–1.5`
- 特に難しい数値や専門語: 必要に応じてさらに長くする

値は固定規則ではなく、実際の読みやすさを優先して調整します。

## 教材一覧

新しい教材を追加したら `lessons/index.json` に登録します。

```json
{
  "id": "example",
  "title": "教材名",
  "topic": "分野",
  "path": "./lessons/topic/example.json"
}
```

JSONの構造は `schema/lesson.schema.json` を正本とします。
