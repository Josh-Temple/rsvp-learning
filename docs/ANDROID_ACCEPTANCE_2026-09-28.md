## RSVP

1. トップで教材を選び、1.0倍で1章を再生する。本文が画面内に収まり、意味単位が読めるか確認する。次に8.0倍で同章を再生し、読めない表示単位の教材IDと該当テキストを記録する。8倍で全内容の理解を合格条件にはしない。表示欠けや極端に読みにくい分割を特定する。
2. 再生中にLibraryを開く。進捗の数値と表示チャンクを控え、数秒待つ。一覧を閉じても数値とチャンクが進まず、明示的な再生操作で続きから進むことを確認する。ALLまたはRNDで章末付近でも、一覧表示中に次章へ勝手に移らないことを確認する。
3. Libraryで異なるCourse / Chapterを素早く続けて選ぶ。最後に選択した章のタイトル・本文・位置表示が一致し、先に選んだ章へ戻らないことを確認する。通信が速く競合を再現できない場合は「判定保留」と記録する。自動回帰テストは応答の逆順を検査済み。
4. 前後のChapter移動、ALL、RNDで、本文と章表示が一致することを確認する。通信エラーを再現できなければ、失敗時の表示について合格扱いにしない。

## Learn

1. COMPLETEの教材からLearnを開き、本文が表示されることを確認する。再生、一時停止、再開、停止を試す。停止は先頭に戻り、再開は同じ段落から続くことを確認する。
2. 日本語音声が複数ある場合、二番目を選んで再生する。音声一覧の更新後も選択が維持され、選択した音声で次の発話が始まることを確認する。一種類のみの場合は音声切替を判定保留にする。
3. 一時停止中に別の音声へ変更する。停止したままで、再生ボタンを押したら現在の段落の先頭から新しい音声で読み直すことを確認する。再生中の音声変更も現在の段落から切り替わることを確認する。
