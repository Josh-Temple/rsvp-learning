SELECTと絞り込み

この章では、エスキューエルでデータを取得し、条件で絞り込み、並べ替える基本操作を学びます。

基本の考え方

まず、SELECTは、データを取得するエスキューエルです。FROMで、対象のテーブルを指定します。必要な列だけを選ぶことができます。WHEREで、条件に合う行を絞り込みます。

関係する用語と要素

次に、等しい、より大きい、含む、などの条件を使えます。複数条件は、ANDやORで組み合わせます。NULLの判定には、IS NULLを使います。

違いと判断の視点

ここで、ORDER BYで、結果を並べ替えます。ASCは昇順、DESCは降順です。DISTINCTは、重複した結果を除くために使えます。LIMITなどで、取得件数を制限できるDBもあります。

利用時に意識する点

最後に、条件を書いたら、意図した行だけ取れているか確認します。大量データでは、不要な全件取得を避けます。エスキューエルは、データ構造を理解して書くことが重要です。

具体例で確かめる

注文表に金額1000円と3000円の二行があるとします。WHERE 金額 >= 2000 なら後者だけが残ります。SELECTで表示する列を指定しても、条件に合う行の判断は変わりません。NULLを含む列は通常の等号比較だけでは期待した結果にならないため扱いを確認します。少数の行で結果を予想し、実際のクエリと照らします。
