クライアント・サーバーとHTTP

この章では、ブラウザなどのクライアントとサーバーがエイチティーティーピーで通信する基本構造を学びます。

基本の考え方

まず、Webシステムでは、クライアントとサーバーが通信します。ブラウザは、代表的なクライアントです。サーバーは、要求を受けて処理し、応答を返します。エイチティーティーピーは、Webで広く使われる通信の仕組みです。

関係する用語と要素

次に、クライアントは、エイチティーティーピー Requestを送ります。サーバーは、エイチティーティーピー Responseを返します。ユーアールエルは、アクセスする資源の場所を示します。

違いと判断の視点

ここで、GETは、情報取得に使われることが多いです。POSTは、新しい処理や登録に使われることが多いです。PUTやPATCHは、更新に使われることがあります。DELETEは、削除を表すために使われます。

利用時に意識する点

最後に、Status Codeは、処理結果の種類を示します。Headerは、通信に関する追加情報を持ちます。Bodyは、送受信するデータ本体を持つことがあります。
