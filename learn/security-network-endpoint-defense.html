ネットワークと端末の防御

境界防御だけに依存せず、分離、通信制御、端末管理、更新、監視を重ねる考え方を学びます。

境界防御だけに頼らない

インターネットとの境界に防御装置を置いても、内部へ入られた後の移動や、内部利用者による誤操作までは防げません。ネットワークを分け、重要資源へ到達できる経路を絞り、必要な通信だけを許します。

ネットワーク内にいること自体を信頼の根拠にせず、利用者や端末なども確認します。

端末を継続して管理する

端末ではOSやアプリケーションを更新し、不要なソフトウェアや過剰な管理者権限を減らします。マルウェア対策製品は有効な層の一つですが、それだけですべての攻撃を防げるわけではありません。

通信と名前解決を監視する

ログや通信量の変化、不審な接続先は異常を知る手掛かりになります。通信が暗号化されていても、その中身が安全とは限りません。DNSのような名前解決も攻撃や障害の対象になるため、通信経路を複数の層で確認します。

侵入後の被害を小さくする

持ち出し端末の紛失や、一部端末への侵入が起きる前提でも設計します。重要資源を分離し、権限を限定し、監視を続けることで、一つの失敗が全体へ広がらないようにします。

この教材の扱う範囲

この章は防御設計の基礎です。具体的なネットワーク構成、端末製品、検知ルールは環境ごとの脅威と要件に合わせて設計します。
