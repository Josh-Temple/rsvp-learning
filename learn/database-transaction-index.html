トランザクションとインデックス

この章では、データ更新の整合性を守るトランザクションと、検索性能を支えるインデックスの基本を学びます。

基本の考え方

まず、トランザクションは、複数の処理を一まとまりとして扱います。途中で失敗した場合、処理を取り消すことがあります。これをrollbackと呼びます。すべて成功したら、変更を確定します。

関係する用語と要素

次に、これをcommitと呼びます。AシーアイDは、トランザクションの代表的な性質を表します。Atomicityは、処理を全部成功か全部失敗にします。

違いと判断の視点

ここで、Consistencyは、整合性を保つことに関係します。Isolationは、同時実行の影響を制御します。Durabilityは、確定した結果を保持する性質です。インデックスは、検索を高速化するための構造です。

利用時に意識する点

最後に、ただし、インデックスにも保存容量と更新コストがあります。すべての列へ付ければ良いわけではありません。整合性と性能は、用途に応じて設計します。
